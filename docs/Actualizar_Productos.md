# Flujo de Actualización de Productos en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario con el rol de administrador para poder actualizar
información de un producto dentro de la aplicación web Moteros Oaxaca.
El objetivo de esta guía es proporcionar instrucciones claras y precisas
que faciliten la operación diaria del sistema.

### 1.1 Rol Requerido

El módulo de Actualización de Productos es accesible para usuarios con
el rol de Administrador.

## 2. Flujo de Actualización de Productos

A continuación, se describe paso a paso el proceso que debe seguir el
usuario administrador para actualizar estados de un producto en el
sistema.

### 2.1 Navegar a Actualización de Productos

Para que el usuario pueda empezar a actualizar productos, se debe ubicar
en la sección de "Actualizar productos".

![](/images/actualizarProductos1.png)

Una vez que se encuentre en la sección ya mencionada, el sistema mostrará
una interfaz con una barra de búsqueda para poder agregar productos a
actualizar.

![](/images/actualizarProductos2.png)

### 2.2 Agregar Productos a Actualizar

Para agregar productos a actualizar, se requiere del código del producto
para digitarlo dentro de la barra de búsqueda y con esto el sistema
permitirá agregar el producto a una tabla en donde se podrán hacer las
modificaciones.

![](/images/actualizarProductos3.png)

### 2.3 Modificar Producto

Una vez agregado el producto, el sistema permitirá modificar múltiples
atributos del producto como lo puede ser el concepto del Kardex, el
inventario que hay de este producto en cada sucursal y su precio junto
con los descuentos que se le pueden aplicar al producto.

![](/images/actualizarProductos4.png)

En caso de querer eliminar el producto de esta lista, el usuario se
tiene que desplazar hacia la derecha y presionar el icono de bote de
basura.

  -----------------------------------------------------------------------
  **Nota:** Cuando el usuario termine de hacer modificaciones al
  producto, solo debe presionar el botón de "Guardar Cambios" para que
  el producto se actualice correctamente.

  -----------------------------------------------------------------------

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de actualización de productos en
el sistema sigue el siguiente orden:

- Ubicarse en la sección de Actualizar Productos.

- Buscar por código el producto o productos a actualizar.

- Actualizar el producto y guardar cambios.
