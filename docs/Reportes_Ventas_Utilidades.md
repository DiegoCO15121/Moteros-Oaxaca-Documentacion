# Módulo de Reportes: Ventas y Utilidades

## 1. Introducción

Este documento describe el proceso para acceder y utilizar la sección de **Ventas y Utilidades** dentro del módulo de reportes del sistema.

---

## 2. Flujo de Ventas y Utilidades

### 2.1 Navegar a Reportes → Ventas y Utilidades

El usuario debe dirigirse al módulo de **Reportes** y seleccionar la opción **Ventas y Utilidades**.

![](/images/ventasUtilidades1.png)

---

### 2.2 Visualización del Dashboard

El sistema permite filtrar por:

- Fechas  
- Sucursales  
- Productos  

El dashboard muestra:

- Total de productos vendidos.  
- Descuentos totales.  
- Ventas totales.  
- Utilidad con descuentos.  

![](/images/ventasUtilidades2.png)

También se presenta una tabla con promedios agrupados por producto.

---

### 2.3 Edición de costos

Cada registro incluye un botón de edición (icono de lápiz) que permite modificar el costo total del producto.

Al seleccionarlo, el sistema despliega un formulario editable.

![](/images/ventasUtilidades3.png)

---

## 3. Resumen del Proceso

1. Ingresar a Reportes → Ventas y Utilidades.  
2. Aplicar filtros.  
3. Analizar métricas de ventas.  
4. Revisar promedios por producto.  
5. Editar costos si es necesario.
