# Módulo de Sucursales en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el uso del módulo de
Sucursales dentro del sistema web de Moteros Oaxaca. Este módulo permite
al Administrador administrar las sucursales con las que cuenta la
empresa y poder hacer uso del sistema en cada sucursal.

### 1.1 Rol Requerido

El módulo de Sucursales es accesible únicamente para usuarios con el rol
de Administrador. A continuación, se describe el rol relevante:

  --------------------- -------------------------------------------------
  **Rol**               **Permisos y Funciones**

  **Administrador**     Tiene acceso exclusivo al módulo de Sucursales.
                        Puede consultar toda la información relacionada a
                        las sucursales.
  --------------------- -------------------------------------------------

## 2. Uso del Módulo de Sucursales.

A continuación, se describe paso a paso cómo el Administrador puede
utilizar el módulo de Sucursales: acceder al dashboard y consultar la
información de las sucursales, así como también crearlas.

### 2.1 Acceso al Módulo de Sucursales

**Paso 1: Navegar al módulo**

El Administrador debe dirigirse al menú lateral (sidebar) del sistema y
hacer clic en la opción \"Sucursales\". Al seleccionarla, el sistema
redirige automáticamente al dashboard del módulo, donde se muestran
todas las sucursales.

![](/images/sucursales1.png)

### 2.2 Dashboard: Sucursales

El dashboard del módulo de Sucursales presenta una tabla con toda la
información de sucursales y también unos botones de acción con los
cuales se pueden editar o eliminar las sucursales.

![](/images/sucursales2.png)

### 2.3 Crear Sucursales

El usuario debe presionar en el botón de "Nuevo", al presionar el botón,
este será redirigido a un formulario para proporcionar información de la
nueva sucursal. El usuario deberá presionar en el botón "Guardar"para
poder crear la sucursal.

![](/images/sucursales3.png)

![](/images/sucursales4.png)

### 2.4 Ajustar los datos de una sucursal

**Paso 1: Presionar sobre icono de lápiz**

El Administrador debe localizar la sucursal que desea modificar dentro
de la tabla y hacer clic sobre el icono de lápiz. El sistema redirigirá
al usuario a un formulario.

**Paso 2: Modificar los valores en el formulario**

El formulario se carga con datos de la sucursal para poder modificarlas.

![](/images/sucursales5.png)

  -----------------------------------------------------------------------
  **Nota:** La dirección IP del formulario es la dirección IP para
  conectar dispositivos como lo pueden ser impresoras. En caso de no
  tener esa característica de la sucursal, se debe dejar una IP genérica.

  -----------------------------------------------------------------------

### 2.5 Eliminar sucursal

Si el usuario desea eliminar una sucursal, debe ubicar el icono de bote
de basura en la sucursal que desea eliminar y presionarlo para que el
sistema lo redirija a ver un resumen de la información de la sucursal a
eliminar y confirmar la eliminación.

![](/images/sucursales6.png)

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de uso del módulo de Sucursal
sigue el siguiente orden:

- Acceder al módulo de sucursal.

- Crear una nueva sucursal y llenar los campos solicitados.

- Editar sucursal existente modificando datos.

- Eliminar sucursal y confirmar eliminación.
