# Centro de Capital Humano: Puestos por Sucursal


## 1\. Introducción

El presente documento describe de manera detallada el uso de la subsección de Puestos por Sucursal dentro del módulo de Centro de Capital Humano del sistema web de Moteros Oaxaca. Esta herramienta permite gestionar los puestos de cada sucursal entre otras acciones.

### 1.1 Rol Requerido

El módulo de Centro de Capital Humano y la subsección de Puestos por Sucursal son accesibles únicamente para usuarios con el rol de Administrador. A continuación, se describe el rol relevante:

### 1.2 Módulo de Centro de Capital Humano

El módulo de Centro de Capital Humano agrupa diversas subsecciones relacionadas con la gestión del personal. Entre ellas se encuentra la subsección de turnos por sucursal, que es el enfoque de este documento.

![](/images/centroCapitalHum1.png)

## 2\. Uso de la Subsección Puestos por Sucursal

A continuación, se describe paso a paso cómo el Administrador puede acceder puestos por sucursal para administrar los puestos que existirán y serán asignados a los trabajadores dentro de la sucursal.

### 2.1 Acceso al Módulo de Centro de Capital Humano

**Paso 1: Navegar al módulo**

El Administrador debe dirigirse al menú lateral del sistema y hacer clic en la sección "Centro de Capital Humano" para expandirla. A continuación, debe seleccionar la opción "Puestos por Sucursal". El sistema redirigirá automáticamente a la interfaz para seleccionar sucursal.

![](/images/centroCapitalHum2.png)

### 2.2 Escoger Sucursal

Una vez dentro de Horarios por sucursal, el sistema muestra las diferentes sucursales que existen y el usuario debe presionar en el botón “Configurar horario” de la sucursal deseada.

![](/images/puestosSucursal1.png)

### 2.3 Visualizar Horario

Una vez elegida la sucursal. El sistema redirigirá al usuario a una interfaz en donde puede definir diferentes turnos para puestos que se requieran en la tienda, eliminarlos o editarlos.

![](/images/puestosSucursal2.png)

**Definir turnos del puesto**

Para que el usuario pueda definir más turnos para un puesto, requiere llenar el formulario que aparece en la interfaz. El usuario también puede seguir añadiendo turnos al mismo puesto presionando el botón que indica esta característica.

![](/images/puestosSucursal3.png)

**Puestos asignados**

Todos horarios que se hayan creado aparecerán en esta sección. Aquellos grupos con el mismo puesto aparecerán del mismo color para hacer más fácil su identificación.

![](/images/puestosSucursal4.png)

**Editar grupo**

Para editar un grupo el usuario debe presionar el botón “Editar Grupo” y el sistema mostrará al usuario el formulario con los datos precargados de los turnos existentes para el puesto.

![](/images/puestosSucursal5.png)

**Borrar Grupo/Turno**

En caso de que el usuario decida borrar un grupo completo, solo debe presionar el botón “Eliminar Grupo” y solo quiere eliminar un turno del grupo, debe presionar el icono de bote de basura.

## 3\. Resumen del Proceso

A modo de referencia rápida, el flujo de uso de la subsección de Puestos por Sucursal sigue el siguiente orden:

- Acceder al módulo desde "Centro de Capital Humano" → "Puestos Por Sucursal" en el sidebar.

- Elegir sucursal.

- Crear puesto y horario.

- Editar Grupo.

- Eliminar grupo u horario.
