# Centro de Capital Humano: Gestión de Vacaciones


## 1\. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de Administrador para gestionar las vacaciones de cada colaborador dentro del módulo de Centro de Capital Humano del sistema web de Moteros Oaxaca. La sección de Vacaciones permite establecer los periodos vacacionales de cada empleado.

### 1.1 Rol Requerido

El módulo de Centro de Capital Humano y la subsección de Vacaciones son accesibles únicamente para usuarios con el rol de Administrador. A continuación, se describe el rol relevante:

### 1.2 Acceso al Módulo de Centro de Capital Humano

El Centro de Capital Humano agrupa diversas subsecciones relacionadas con la gestión del personal de la empresa. Para acceder a cualquiera de ellas, el Administrador debe seguir los mismos pasos descritos a continuación.

**Paso 1: Navegar al módulo desde el sidebar**

El Administrador debe dirigirse al menú lateral (sidebar) del sistema y hacer clic en la opción "Centro de Capital Humano". Al seleccionarla, el sistema redirige automáticamente al dashboard principal del módulo.

![](/images/centroCapitalHum1.png)

**Paso 2: Seleccionar la subsección de Vacaciones**

Dentro del dashboard del Centro de Capital Humano, el Administrador puede visualizar todas las subsecciones disponibles organizadas en tarjetas. Para acceder a la gestión de Vacaciones, debe hacer clic en la tarjeta "Vacaciones" o presionar el botón "Ir" correspondiente.

![](/images/centroCapitalHum2.png)

## 2\. Gestión de Vacaciones

A continuación, se describe paso a paso cómo el Administrador puede gestionar las vacaciones de los colaboradores en el sistema.

### 2.1 Dashboard de Vacaciones

Una vez dentro de la subsección, el sistema presenta una tabla con todos los colaboradores. Cada registro muestra el nombre del colaborador, sucursal perteneciente, días otorgados, gozados, disponibles y solicitudes pendientes.

Desde este dashboard es posible realizar las siguientes acciones:

- Buscar colaboradores mediante la barra de búsqueda en la parte superior.

- Filtrar por estatus.

- Administrar periodos mediante el botón “Periodos”.

- Administrar Solicitudes.

![](/images/vacaciones1.png)

### 2.2 Administrar Periodos

**Paso 1: Abrir el formulario de Periodos**

Desde el dashboard, el Administrador debe hacer clic en el botón "Periodos" correspondiente al usuario que se desea administrar su periodo.

**Paso 2: Editar periodos**

El formulario está organizado en dos secciones. La primare sección es para ver los periodos ya asignados al usuario y con posibilidad de edición, en caso de que se requiera. Después de la edición debe presionar el botón Guardar

![](/images/vacaciones2.png)

**Paso 3: Crear periodos**

La segunda sección es para crear periodos vacacionales al colaborados. El sistema carga valores por defecto para este formulario, pero si el administrador quisiera alterar estos datos, lo puede hacer sin ningún problema y después deberá presionar el botón de “Guardar periodo”

> Nota: No se pueden crear dos periodos que tengan el mismo año para un colaborador.

**Paso 4: Eliminar Periodo**

Para eliminar un periodo el usuario solo debe presionar en el botón “Eliminar” y después confirmarle la eliminación al sistema.

![](/images/vacaciones3.png)

### 2.3 Administrar Solicitudes

**Paso 1: Abrir sección de solicitudes**

El usuario debe presionar el botón de “Ver solicitudes” ubicado en la parte superior derecha. Una vez presionado el botón, el sistema redirigirá al usuario a la sección de Solicitudes de vacaciones.

![](/images/vacaciones4.png)

**Paso 2: Aprobar o Rechazar solicitudes**

El usuario debe presionar el botón “Ver detalle” en el registro deseado y con ello el sistema mostrará el detalle del permiso y el administrador tendrá que presionar entre “Aceptar” o “Rechazar” según desee.

![](/images/vacaciones5.png)
