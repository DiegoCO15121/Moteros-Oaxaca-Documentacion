# Módulo de Ecommerce: Grupos de Categorías

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de administrador para gestionar los grupos de categorías dentro del módulo de Ecommerce del sistema web de Moteros Oaxaca. El objetivo de esta guía es proporcionar instrucciones claras y precisas que faciliten la operación del sistema.

Los grupos de categorías permiten organizar y agrupar las categorías de productos que se muestran en la tienda en línea, facilitando la navegación de los clientes.

---

## 2. Flujo de Gestión de Grupos de Categorías

A continuación, se describe paso a paso el proceso que debe seguir el administrador para gestionar los grupos de categorías en el sistema de manera exitosa.

### 2.1 Navegar a Grupos de Categorías

El usuario debe dirigirse al menú lateral, expandir la sección de **Ecommerce** y seleccionar la opción de **Grupos de categorías**.

![](/images/GruposCategoria1.png)

Una vez dentro, el sistema mostrará el dashboard con el listado de grupos de categorías registrados.

![](/images/GruposCategoria2.png)

---

### 2.2 Crear grupo de categorías

**Paso 1: Abrir formulario**

El usuario debe presionar el botón de **“Nuevo”** ubicado en la parte superior del dashboard.

**Paso 2: Completar y guardar**

Debe ingresar la información requerida en el formulario y presionar **“Guardar”** para registrar el nuevo grupo.  
Si desea cancelar, puede presionar **“Regresar”**.

![](/images/GruposCategoria3.png)

> Nota: Los campos obligatorios deben completarse antes de guardar. De lo contrario, el sistema mostrará un mensaje de advertencia.

---

### 2.3 Editar grupo de categorías

**Paso 1: Seleccionar registro**

El usuario debe ubicar el grupo que desea editar y presionar el icono de lápiz.

**Paso 2: Modificar y guardar**

El sistema mostrará el formulario con los datos precargados.  
Se realizan los cambios necesarios y se presiona **“Guardar”**.

![](/images/GruposCategoria4.png)

---

### 2.4 Eliminar grupo de categorías

**Paso 1: Seleccionar registro**

El usuario debe presionar el icono de papelera en el grupo que desea eliminar.

**Paso 2: Confirmar eliminación**

El sistema solicitará confirmación antes de eliminar el registro de forma definitiva.

![](/images/GruposCategoria5.png)

> Nota: La eliminación es permanente e irreversible. Se recomienda verificar que el grupo no esté en uso antes de eliminarlo.

---

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de gestión de grupos de categorías sigue el siguiente orden:

1. Ingresar a Ecommerce → Grupos de categorías.  
2. Visualizar el listado de grupos.  
3. Crear un nuevo grupo.  
4. Editar un grupo existente.  
5. Eliminar un grupo si es necesario.
