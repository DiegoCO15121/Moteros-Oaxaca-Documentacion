# Módulo de General: Sección de Configuración


## 1\. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de Administrador para gestionar la configuración dentro del sistema web de Moteros Oaxaca.

### 1.1 Rol Requerido para la Gestión

El módulo de General es accesible únicamente para usuarios con el rol de Administrador.

## 2\. Gestión de Configuración General

A continuación, se describe paso a paso como el Administrador puede gestionar los roles del sistema: acceder al módulo, visualizar el listado, crear nuevos roles, editarlos y eliminarlos.

### 2.1 Acceso al Módulo de General

**Paso 1: Navegar al modulo**

El Administrador debe dirigirse al menú lateral (sidebar) del sistema y hacer clic en la opción "General", ubicada dentro de la sección de Configuración. Al seleccionarla, el sistema redirige automáticamente al dashboard del módulo.

![](/images/generalConfig1.png)

### 2.2 Dashboard de General

Una vez dentro del módulo, el Administrador puede ver el listado de las configuraciones generales que puede hacer dentro del sistema.

- Cambiar serie y folio de cotización.

- Cambiar dirección de la página web

- Cambiar el correo de la empresa.

- Editar el nombre de las redes sociales de la empresa.

![](/images/generalConfig2.png)

### 2.3 Edición de Configuración General

**Paso 1: Seleccionar registro deseado**

Desde el dashboard, el Administrador debe hacer clic en el botón "Editar" dentro del registro a configurar.

**Paso 2: Actualizar datos y guardar**

Cada opción de configuración tiene su propio campo de texto para editar el valor actual de la característica. Al terminar de editar la característica del sistema, solo debe presionar “Guardar cambios”.
