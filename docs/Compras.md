# Flujo de Compras en el sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de administrador o vendedor para gestionar compras dentro del sistema web de Moteros Oaxaca. El objetivo de esta guía es proporcionar instrucciones claras y precisas que faciliten la operación del módulo de compras.

## 2. Flujo de Compras

A continuación, se describe paso a paso el proceso que debe seguir el usuario administrador para gestionar compras en el sistema de manera exitosa.

**Paso 1: Navegar a Compras**

El usuario debe dirigirse a la sección de **Compras** desde la navegación lateral del sistema.

![](/images/compras1.png)

Una vez dentro, el sistema mostrará todas las compras registradas.

![](/images/compras2.png)

---

**Paso 2: Crear compra**

Para crear una compra, el usuario debe presionar el botón de **“Nuevo”**. El sistema lo redirigirá a una página donde podrá:

- Descargar una plantilla de Excel.  
- Rellenar la plantilla con la información requerida.  
- Subir el archivo para generar la compra en el sistema.

![](/images/compras3.png)

---

**Paso 3: Editar compra**

Para editar una compra, el usuario debe presionar el botón con icono de lápiz. El sistema lo redirigirá a una página donde podrá modificar:

- Ajuste de precio de compra.  
- Ajuste de precio de venta.  
- Descuentos aplicables.  

Una vez realizados los cambios, el usuario debe presionar el botón de **“Guardar”**.

Si desea confirmar la compra, debe presionar el botón de **“Confirmar Compra”**.

![](/images/compras4.png)  
![](/images/compras5.png)

---

**Paso 4: Ver detalles de compra**

Para visualizar los detalles de una compra, el usuario debe presionar el botón con icono de **información (i)**. El sistema lo redirigirá a una vista donde podrá revisar toda la información registrada.

![](/images/compras6.png)

---

**Paso 5: Eliminar compra**

Para eliminar una compra, el usuario debe presionar el botón con icono de bote de basura en el registro correspondiente y confirmar la acción.

![](/images/compras7.png)

---

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de compras en el sistema sigue el siguiente orden:

1. Ingresar a la sección de Compras.  
2. Crear la compra mediante la carga de la plantilla de Excel.  
3. Editar la compra si es necesario.  
4. Confirmar la compra.  
5. Consultar detalles de la compra.  
6. Eliminar la compra en caso necesario.
