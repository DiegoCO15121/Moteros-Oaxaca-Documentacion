# Flujo de Apertura de Caja en el Sistema


## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario con el rol de vendedor para realizar apertura
de caja dentro del sistema web de Moteros Oaxaca. El objetivo de esta
guía es proporcionar instrucciones claras y precisas que faciliten la
operación diaria del sistema.

## 2. Flujo de Apertura de Caja

**Paso 1: Apertura de Caja**

Para iniciar el proceso de apertura de caja, el usuario vendedor debe
dirigirse a la sección de "Inicio" del sistema. En esta sección se
mostrarán todas las cajas disponibles. Para abrir una caja, el usuario
deberá hacer clic en el botón \"Abrir Caja\" correspondiente a la caja
que desea utilizar.

![](/images/caja1.png)

Al presionar en el botón indicado, el sistema redirige al usuario a un
formulario de apertura de caja. En dicho formulario se deberán
proporcionar los siguientes datos:

- Conteo de efectivo existente al momento de la apertura.

- Código de vendedor.

- Nota de apertura (campo opcional).

![](/images/caja2.png)

Una vez completados los campos requeridos, el usuario deberá hacer clic
en el botón \"Abrir Caja\" para confirmar la apertura y dar inicio a la
jornada de ventas.

![](/images/caja3.png)

![](/images/caja4.png)

  --------------------------------------------------------------------
  Nota: Es indispensable realizar apertura de caja para realizar
  ventas, devoluciones, facturaciones y cotizaciones en línea.
