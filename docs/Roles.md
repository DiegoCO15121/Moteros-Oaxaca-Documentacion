# Módulo de Roles: Gestión de Roles

## 1\. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de Administrador para gestionar los roles dentro del sistema web de Moteros Oaxaca. El módulo de Roles permite crear los roles que pueden ser seleccionados en el módulo de usuarios. En esta sección se puede personalizar a que paginas tiene acceso cada rol.

## 2\. Gestión de Roles

A continuación, se describe paso a paso como el Administrador puede gestionar los roles del sistema: acceder al módulo, visualizar el listado, crear nuevos roles, editarlos y eliminarlos.

### 2.1 Acceso al Módulo de Roles

**Paso 1: Navegar al modulo**

El Administrador debe dirigirse al menú lateral (sidebar) del sistema y hacer clic en la opción "Roles", ubicada dentro de la sección de Configuración. Al seleccionarla, el sistema redirige automáticamente al dashboard del módulo, donde se muestra el listado de todas las cuentas registradas.

![](/images/roles1.png)

### 2.2 Dashboard de Roles

Una vez dentro del módulo, el Administrador puede ver el listado completo de roles registrados en el sistema. La tabla muestra los siguientes datos por cada cuenta: Nombre del rol, descripción, estatus, fecha de creación y acciones que se pueden realizar con cada rol.

Desde este dashboard es posible realizar las siguientes acciones:

- Buscar roles mediante la barra de búsqueda en la parte superior.

- Registrar un nuevo rol mediante el botón "Nuevo".

- Editar un registro existente presionando el icono de lápiz.

- Eliminar un registro presionando el icono de papelera.

![](/images/roles2.png)

### 2.3 Registrar un Nuevo Rol

**Paso 1: Abrir el formulario de nuevo rol**

Desde el dashboard, el Administrador debe hacer clic en el botón "Nuevo" ubicado en la esquina superior derecha. El sistema redirigirá al formulario de registro titulado "Nuevo Rol".

**Paso 2: Completar el formulario y guardar**

El formulario pide el nombre del rol, la descripción y el estatus. Después el sistema de manera opcional pedirá seleccionar las páginas o módulos a los cuales el rol tendrá acceso.

![](/images/roles3.png)

Una vez completados todos los campos requeridos, el Administrador debe hacer clic en el botón "Guardar" para registrar al nuevo rol en el sistema. Si desea cancelar la operación, puede presionar el botón "Regresar".

### 2.4 Editar un Rol

**Paso 1: Seleccionar el rol a editar**

En el dashboard, el Administrador debe localizar el rol que desea modificar y hacer clic en el icono de lápiz que aparece en la columna de "Acciones" del registro correspondiente.

**Paso 2: Modificar los datos**

El sistema redirigirá al formulario "Editar Rol" con todos los datos actuales del registro precargados y listos para editar.

**Paso 3: Guardar los cambios o usar acciones adicionales**

Una vez realizadas las modificaciones, el Administrador dispone de las siguientes opciones en la parte inferior del formulario:

- Guardar: Aplica los cambios realizados en el registro del rol.

- Regresar: Cancela la edición y vuelve al dashboard sin guardar cambios.

![](/images/roles4.png)

### 2.5 Eliminar un Rol

**Paso 1: Seleccionar el rol a eliminar**

En el dashboard, el Administrador debe localizar el rol que desea eliminar y hacer clic en el icono de papelera que aparece en la columna de "Acciones" del registro correspondiente.

**Paso 2: Confirmar la eliminación**

El sistema redirigirá a la vista "Eliminar Rol", que muestra todos los datos actuales del rol en modo de solo lectura. El Administrador debe revisar que el registro sea el correcto y, a continuación, hacer clic en el botón "Eliminar" para proceder con la eliminación definitiva. Si desea cancelar la operación, puede presionar el botón "Regresar".

![](/images/roles5.png)

> Nota: La eliminación de una cuenta de rol es una acción permanente e irreversible. Una vez confirmada, el rol no se encontrará sistema.

## 3\. Resumen del Proceso

A modo de referencia rápida, las acciones disponibles en el módulo de Roles siguen el siguiente flujo:

- Acceder al módulo desde la opción "Rol" en la sección de configuración del sidebar.

- Visualizar el listado de roles en el dashboard y usar la busqueda si es necesario.

- Registrar un nuevo rol con el botón "Nuevo".

- Editar un rol presionando el icono de lápiz, modificar los datos y guardar.

- Eliminar un rol presionando el icono de papelera, revisar los datos en la vista de confirmación y presionar "Eliminar".
