# Módulo de Ecommerce: Gestión de Productos Tienda

## 1. Introducción

El presente documento describe de manera detallada el uso del módulo de
Ecommerce dentro del sistema web de Moteros Oaxaca. Este módulo permite
al Administrador gestionar el contenido que se muestra en la tienda en
línea de la empresa.

Este documento se enfoca específicamente en la subsección de Productos
Tienda. Los productos tienda son los productos que están disponibles en
la tienda en línea.

### 1.1 Rol Requerido

El módulo de Ecommerce y todas sus subsecciones son accesibles
únicamente para usuarios con el rol de Administrador. A continuación, se
describe el rol relevante:

  -----------------------------------------------------------------------
  **Rol**               **Permisos y Funciones**

  **Administrador**     Tiene acceso exclusivo al módulo de Ecommerce.
                        Puede gestionar todos los contenidos de la tienda
                        en línea, incluyendo la creación y eliminación de
                        productos tienda.

  -----------------------------------------------------------------------

1.2 Subsecciones del Módulo de Ecommerce

El módulo de Ecommerce agrupa las siguientes subsecciones, cada una
enfocada en un elemento diferente de la tienda en línea:

![](/images/tienda1.png)

2\. Gestión de Productos Tienda

La subsección de Productos en Tendencia permite al Administrador
gestionar los productos destacados que se muestra en la página principal
de la tienda en línea.

![](/images/tienda2.png)

A continuación, se describe paso a paso cómo el Administrador añadir y
eliminar productos tienda.

2.1 Acceso a la Subsección de Productos Tienda

**Paso 1: Navegar al módulo de Ecommerce**

El Administrador debe dirigirse al menú lateral (sidebar) del sistema y
hacer clic en la sección \"Ecommerce\" para expandir sus subsecciones. A
continuación, debe seleccionar la opción \"Productos Tienda\". El
sistema redirigirá automáticamente al dashboard del carrusel de
productos en tienda.

### 2.2 Dashboard de Productos Tienda

Una vez dentro de la subsección, el Administrador puede ver el listado
completo de productos tienda registrados.

Desde este dashboard es posible realizar las siguientes acciones:

- Buscar productos mediante la barra de búsqueda en la parte superior.

- Crear un nuevo anuncio mediante el botón \"Nuevo\".

- Eliminar un producto presionando el ícono de papelera.

![](/images/tienda3.png)

### 2.3 Crear un Nuevo Producto Tienda

**Paso 1: Buscar el Producto Tienda**

Desde el dashboard en la barra de búsqueda, el usuario debe ingresar el
código del producto y de esta manera el sistema buscará el producto
relacionado a ese código y permitirá agregarlo a productos tienda. En
caso de que el producto ya se encuentre en la lista de productos en
tienda, el sistema alertará que el producto ya se encuentra en la lista.

![](/images/tienda4.png)

2.4 Eliminar un Producto Tienda

**Paso 1: Seleccionar el producto a eliminar**

En el dashboard de producto tienda, el Administrador debe localizar el
producto que desea eliminar y presionar en el ícono de papelera que
aparece en la columna de \"Acciones\" del registro correspondiente.

**Paso 2: Confirmar la eliminación**

Al presionar el ícono de eliminar, el sistema mostrará una ventana de
confirmación con el mensaje \"¿Estás seguro?\" advirtiendo que la
eliminación de producto tienda no podrá revertirse. El Administrador
debe hacer clic en el botón \"Sí, eliminar\" para proceder con la
eliminación definitiva del producto tienda. Si desea cancelar la
operación, puede presionar el botón \"Cancelar\".

![](/images/tienda5.png)

## 3. Resumen del Proceso

A modo de referencia rápida, las acciones disponibles en la subsección
de Productos Tienda del módulo de Ecommerce siguen el siguiente flujo:

- Acceder al módulo desde la sección \"Ecommerce\" del sidebar y
  seleccionar \"Productos Tienda\".

- Visualizar el listado de productos tienda en el dashboard.

- Crear un nuevo anuncio buscándolo en la barra de búsqueda y
  agregándolo.

- Eliminar un producto en tienda presionando el ícono de papelera y
  confirmando la acción en la ventana de confirmación.
