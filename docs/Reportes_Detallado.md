# Módulo de Reportes: Detallado

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de administrador para ver los reportes correspondientes a las ventas diarias dentro del sistema web de Moteros Oaxaca. El objetivo de esta guía es proporcionar instrucciones claras y precisas que faciliten la operación diaria del sistema.

## 2. Flujo de Detallado 

A continuación, se describe paso a paso el proceso que debe seguir el usuario administrador para consultar el detalle de las ventas diarias.

**Paso 1: Detallado**

El usuario debe dirigirse a la sección de “Detallado” dentro del módulo de Reportes

![](/images/ReportesDetallado1.png)


Dentro de esta sección el usuario puede filtrar las ventas por medio de los filtros de sucursales, vendedores, métodos de pago, estado y la barra de búsqueda por folio.

![](/images/ReportesDetallado2.png)


El usuario podrá visualizar el detalle de las ventas según el rango de fechas seleccionado actualmente y también tendrá la opción de descargar el reporte diario en formato PDF o Excel.
