# Flujo de Venta en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario con el rol de vendedor para registrar una
venta dentro del sistema web de Moteros Oaxaca. El objetivo de esta guía
es proporcionar instrucciones claras y precisas que faciliten la
operación diaria del sistema.

### 1.1 Roles del Sistema

El sistema cuenta con diferentes roles de usuario, cada uno con permisos
específicos:

  -------------------- -----------------------------------------------
  **Rol**              **Permisos y Funciones**

  **Vendedor**         Es el rol responsable de gestionar y registrar
                      las ventas en el sistema. Tiene acceso completo
                       al flujo de venta descrito en este manual.

  -------------------- -----------------------------------------------

## 2. Flujo de Venta

A continuación, se describe paso a paso el proceso que debe seguir el
usuario vendedor para registrar una venta de forma exitosa en el
sistema.

  --------------------------------------------------------------------
  **Nota:** Para poder realizar una venta se requiere de abrir una
  caja antes de continuar. Este proceso está documentado en el
  documento de flujo de apertura de una caja.

  --------------------------------------------------------------------

**Paso 1: Selección de Productos**

Con la caja abierta, el usuario deberá dirigirse a la sección de
Productos para agregar los artículos deseados al carrito de compra.

  --------------------------------------------------------------------
  **Nota:** Únicamente los productos con existencia disponible en la
  sucursal mostrarán el ícono de carrito al pasar el cursor sobre
  ellos. Si un producto no muestra este ícono, indica que no cuenta
  con inventario disponible.

  --------------------------------------------------------------------

![](/images/ventas1.png)

Al agregar uno o varios productos al carrito, estos se mostrarán en un
panel lateral ubicado en el lado derecho de la pantalla. Desde este
panel el usuario podrá realizar las siguientes acciones sin necesidad de
salir de la sección de productos:

- Modificar la cantidad de cada producto.

- Eliminar un producto del carrito.

![](/images/ventas2.png)

**Paso 3: Revisión del Carrito de Compra**

Para acceder al detalle completo del carrito y continuar con el proceso
de venta, el sistema ofrece dos opciones:

1.  Hacer clic en el ícono de carrito ubicado en la parte superior del
    sistema, el cual muestra un contador en color rojo indicando el
    número de productos agregados.

2.  Hacer clic en el botón \"Ir al Carrito\" que se encuentra en la
    parte superior del panel lateral derecho.

Una vez dentro de la vista de detalle del carrito, el usuario podrá
realizar las siguientes acciones antes de proceder con la venta:

- Ajustar la cantidad de venta de cada producto.

- Consultar el precio unitario e importe total por producto.

- Aplicar un descuento (el porcentaje de descuento varía según el tipo
  de cliente).

- Seleccionar la ubicación o almacén de donde se tomará el producto
  (campo obligatorio).

- Aplicar un código de descuento en caso de contar con uno.

- Guardar o descargar una cotización si el cliente así lo requiere.

![](/images/ventas3.png)

Una vez que el usuario haya validado la información del carrito, deberá
hacer clic en el botón \"Continuar con el Checkout\" para avanzar al
siguiente paso.

**Paso 4: Proceso de Checkout**

En la pantalla de checkout, el usuario deberá seleccionar las
preferencias de pago y entrega del cliente. Los datos requeridos en esta
etapa son los siguientes:

- Forma de pago preferida por el cliente.

- Método de entrega: En tienda, Pedido Local o Pedido Foráneo.

![](/images/ventas4.png)

**Paso 5: Finalización de la Venta**

Para concluir el proceso de venta, el usuario deberá verificar que todos
los campos del formulario estén correctamente completados y, a
continuación, hacer clic en el botón \"Finalizar Venta\".

  --------------------------------------------------------------------
  **Nota:** Es indispensable que todos los campos obligatorios estén
  debidamente rellenados antes de intentar finalizar la venta. Si
  algún campo requerido está vacío o contiene información incorrecta,
  el sistema no permitirá completar la transacción.

  --------------------------------------------------------------------

![](/images/ventas8.png)

Si toda la información es correcta, la venta se registrará de manera
exitosa en el sistema y el proceso habrá concluido.

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de venta en el sistema sigue el
siguiente orden:

1.  Abrir la caja correspondiente desde la sección de Inicio.

2.  Ingresar los datos de apertura de caja (efectivo, código de
    vendedor, nota opcional).

3.  Seleccionar los productos con existencia desde la sección de
    Productos.

4.  Revisar y ajustar el carrito de compra (cantidades, descuentos,
    ubicación).

5.  Seleccionar la forma de pago y el método de entrega en el checkout.

6.  Hacer clic en \"Finalizar Venta\" para completar el registro.
