# Flujo de Producto Negado en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario con el rol de vendedor para registrar un
producto negado dentro del sistema web de Moteros Oaxaca. El objetivo de
esta guía es proporcionar instrucciones claras y precisas que faciliten
la operación diaria del sistema

## 2. Flujo de Producto Negado

A continuación, se describe paso a paso el proceso que debe seguir el
usuario vendedor para registrar un producto negado de forma exitosa en
el sistema.

**Paso 1: Agregar Productos Negados**

El usuario debe dirigirse a la sección "Productos negados" dentro del
sistema, presionando el botón de prohibido en la parte superior derecha
de la interfaz.

![](/images/negados1.png)

Después de presionar el botón el usuario verá un modal con un formulario
para llenar con la información del producto negado.

![](/images/negados2.png)

![](/images/negados3.png)

El usuario deberá presionar el botón guardar si quiere guardar el
producto negado.

**Paso 2: Visualización de productos negados**

El usuario debe dirigirse a la sección "Productos negados" dentro del
sistema.

![](/images/negados4.png)

En esa sección se podrán buscar los productos negados añadidos o editar
los ya existentes.

**Paso 3: Visualización de detalles de productos negados**

El usuario debe presionar el botón con icono de ojo y el sistema abrirá
un modal con un formulario con la información del producto negado para
revisar a detalle sus características.

![](/images/negados5.png)

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de productos negados en el sistema
sigue el siguiente orden:

1.  Presionar el botón de prohibido para agregar producto negado.

2.  Agregar producto negado.

3.  Moverse a sección de productos negados.

4.  Elegir producto a visualizar detalles.

5.  Presionar botón de inspección.
