# Flujo de Marcas en el sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de administrador para gestionar las marcas dentro del sistema web de Moteros Oaxaca. El objetivo de esta guía es proporcionar instrucciones claras y precisas que faciliten la operación del módulo de marcas.

## 2. Flujo de Marcas

A continuación, se describe paso a paso el proceso que debe seguir el usuario administrador para gestionar las marcas en el sistema de manera exitosa.

**Paso 1: Navegar a Marcas**

El usuario debe dirigirse a la sección de **Marcas** desde la navegación lateral del sistema.

![](/images/marcas1.png)

Una vez dentro, el sistema mostrará todas las marcas registradas, con opciones para agregar, editar, buscar y eliminar.

![](/images/marcas2.png)

---

**Paso 2: Crear marca**

Para crear una nueva marca, el usuario debe presionar el botón de **“Nuevo”**. El sistema mostrará un formulario donde deberá ingresar la información correspondiente.

![](/images/marcas3.png)

---

**Paso 3: Editar marca**

Para editar una marca, el usuario debe presionar el botón con icono de lápiz. El sistema lo redirigirá a un formulario con los datos precargados para su modificación.

![](/images/marcas4.png)

---

**Paso 4: Eliminar marca**

Para eliminar una marca, el usuario debe presionar el botón con icono de bote de basura en el registro correspondiente y confirmar la acción.

![](/images/marcas5.png)

---

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de marcas en el sistema sigue el siguiente orden:

1. Ingresar a la sección de Marcas.  
2. Crear una nueva marca.  
3. Editar la marca si es necesario.  
4. Eliminar la marca.
