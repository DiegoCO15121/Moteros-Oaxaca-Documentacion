# Flujo de Cajas en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario con el rol de administrador para administrar las cajas
de las sucursales en el sistema web de Moteros Oaxaca. El objetivo de esta
guía es proporcionar instrucciones claras y precisas que faciliten la
operación diaria del sistema.

### 1.1 Rol Requerido

El módulo de Cajas es accesible para usuarios con el rol de Administrador.

## 2. Flujo de Cajas

Para que el usuario pueda acceder al módulo de Cajas, se debe ubicar en la sección de “Cajas” de la navegación lateral.

![](/images/caja1.png)

Una vez que se encuentre en la sección ya mencionada, el sistema mostrará todas las cajas con la opción de ver detalles en cada una de ellas.

![](/images/caja2.png)

### 2.2 Ver detalles de una caja

Para ver los detalles de una caja, el usuario debe presionar el botón de “Ver detalles” en la caja a inspeccionar. El sistema mostrara una interfaz que se maneja mediante filtros, los filtros toman una fecha de inicio y fin para poder el historial de sesiones en ese rango de fechas dadas por el usuario, a la vez que el sistema muestra el dinero acumulado del día en curso.

![](/images/caja3.png)

### 2.3 Ver desglose de cierre

El sistema permite que el usuario pueda ver el detalle de cierre de la sesión de una caja, el usuario debe presionar el botón “Ver Desglose de Cierre” y el sistema desplegara todo el detalle del cierre de la sesión.

![](/images/caja4.png)

Adicionalmente el sistema permite imprimir el ticket de cada sesión, para ello el usuario puede presionar “Re-imprimir Ticket” dentro del mismo detalle de la sesión o directamente presionando “Imprimir Ticket” en el resumen de la sesión.

# 3. Resumen del Proceso

A modo de referencia rápida, el flujo de Cajas en el sistema sigue el siguiente orden:

- Ubicarse en la sección de Cajas.

- Seleccionar una caja a inspeccionar.

- Establecer rango del historial de sesiones.

- Ver detalle de cada sesión e imprimir tickets.
