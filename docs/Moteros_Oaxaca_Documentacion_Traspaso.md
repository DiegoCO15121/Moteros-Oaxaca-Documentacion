# Flujo de Traspaso de Productos en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario con el rol de vendedor (seller) para registrar un
traspaso de productos dentro del sistema web de Moteros Oaxaca. El
objetivo de esta guía es proporcionar instrucciones claras y precisas
que faciliten la operación diaria del sistema.

# 2. Flujo de Traspaso de Productos

A continuación, se describe paso a paso el proceso que debe seguir el
usuario vendedor para hacer un traspaso de forma exitosa en el sistema.

## **2.1 Traspaso de Productos**

**Paso 1: Identificación del producto a traspasar**

El usuario vendedor debe dirigirse a la sección "Productos". Una vez ahí
debe ubicar el producto del cual quiere hacer traspasos. Una vez
identificado el producto, el usuario hará clic en el kardex del
producto.

![](/images/image1.png)

Una vez dentro del kardex del producto el usuario puede filtrar los
movimientos que se han hecho relacionados al producto mediante los
filtros ubicados en la parte superior del sistema.

![](/images/image2.png)

**Paso 2: Ejecución del Traspaso**

Para generar un nuevo traspaso el usuario debe presionar el botón
"Nuevo" ubicado en la parte superior derecha. En el formulario el
usuario vendedor deberá seguir los siguientes pasos:

- Seleccionar como tipo de movimiento "Traspaso".

- Introducir la cantidad del producto a traspasar.

- Elegir la sucursal de destino del traspaso.

- Detallar el movimiento que se está haciendo.

- Ingresar código de vendedor.

- Presionar "Guardar".

![](/images/image3.png)

**Paso 3: Envío de Producto (detalles del kardex)**

Una vez guardado el traspaso el usuario será redirigido a ver los
detalles del Kardex del proceso de traspaso, en el cual deberá validar
la información y además tendrá la posibilidad de cargar una imagen de la
evidencia del traspaso (no es obligatorio) y poder modificar la cantidad
del traspaso asi como detallar el movimiento de este mismo.

![](/images/image4.png)

![](/images/image5.png)

Cuando el usuario vendedor haya confirmado que toda la información del
detalle es válida, debe presionar el botón "Enviar" y se le notificará a
la sucursal de destino el traspaso que este proceso de completarse. En
caso de que el usuario ya no desee hacer el traspaso, deberá presionar
"Cancelar" para cancelar el proceso.

**Paso 3.1: Envío de Producto (flujo secundario).**

En caso de que el usuario presione el botón "Lista", este será
redirigido al dashboard de traspasos y el traspaso quedará en estado de
pendiente, esperando por una confirmación o cancelación del proceso.

![](/images/image6.png)

En caso de que el usuario quiera cancelar o proceder con el proceso,
deberá presionar el botón "i" y el usuario será redirigido al detalle de
Kardex.

En caso de confirmar el proceso de traspaso, el sistema actualizara el
estado del traspaso a "Enviado" y la cantidad de producto disponible en
la sucursal se reduce según la cantidad que se haya enviado.

![](/images/image7.png)

![](/images/image8.png)

**Paso 4: Proceder con el Traspaso (sucursal de destino)**

En el sistema de la sucursal de destino se le notificara al usuario
vendedor que una sucursal le ha hecho un traspaso de producto (la
notificación también podrá ser vista desde la sección de notificaciones)

![](/images/image9.png)

![](/images/image10.png)

Para proceder se puede presionar en la notificación (en caso de usar el
acceso rápido ubicado en la parte superior derecha) o presionar el botón
de ojo de la notificación correspondiente dentro del dashboard.

**Paso 5: Detalles del Kardex de recibimiento de traspaso**

Al momento de presionar ver los detalles de la notificación el usuario
será redirigido al detalle del Kardex del traspaso y este tendrá la
posibilidad de subir evidencia sobre el traspaso del producto y también
detallar el movimiento.

![](/images/image11.png)

![](/images/image12.png)

**Paso 5.1: Flujo de rechazo de traspaso**

En caso de que el usuario presione el botón "Rechazar". El sistema
mostrará un mensaje con múltiples opciones que el usuario vendedor
deberá elegir según sea el caso.

![](/images/image13.png)

En caso de que el usuario seleccione "Devolver" o "No llegó", el estado
del traspaso se actualizará como envío fallido y el stock del producto
restado será devuelto a su estado antes de hacer el traspaso.

![](/images/image14.png)

**Paso 5.2: Flujo de aceptación del traspaso**

Cuando el usuario presione el botón de "Recibido", el estado del
traspaso pasa a ser finalizado.

![](/images/image16.png)

![](/images/image17.png)

  --------------------------------------------------------------------
  **Nota:** El stock del producto de la tienda que hizo el traspaso se
  queda con el balance final mostrado antes de hacer el traspaso y el
  stock del producto de la tienda a la cual le llegó el envío aumenta
  según la cantidad de piezas de producto enviada.

  --------------------------------------------------------------------

# ## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de traspaso en el sistema sigue el
siguiente orden:

1.  Seleccionar el producto a traspasar.

2.  Detallar la cantidad de producto a traspasar y la sucursal de
    destino.

3.  Detallar el Kardex de envío del producto.

4.  En la sucursal de destino, elegir si se rechaza o acepta el envío.

5.  Comprobar el stock del producto de ambas tiendas.
