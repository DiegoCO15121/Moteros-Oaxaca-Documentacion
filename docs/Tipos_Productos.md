# Flujo de Tipos de Productos en el sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de administrador para gestionar los tipos de productos dentro del sistema web de Moteros Oaxaca. El objetivo de esta guía es proporcionar instrucciones claras y precisas que faciliten la operación del módulo de tipos de productos.

## 2. Flujo de Tipos de Productos

A continuación, se describe paso a paso el proceso que debe seguir el usuario administrador para gestionar los tipos de productos en el sistema de manera exitosa.

**Paso 1: Navegar a Tipos de Productos**

El usuario debe dirigirse a la sección de **Tipos de Productos** desde la navegación lateral del sistema.

![](/images/tipoProductos1.png)

Una vez dentro, el sistema mostrará los tipos de productos registrados, con opciones para agregar, editar, buscar y eliminar.

![](/images/tipoProductos2.png)

---

**Paso 2: Crear tipo de producto**

Para crear un nuevo tipo de producto, el usuario debe presionar el botón de **“Nuevo”**. El sistema mostrará un formulario donde deberá ingresar la información correspondiente.

![](/images/tipoProductos3.png)

---

**Paso 3: Editar tipo de producto**

Para editar un tipo de producto, el usuario debe presionar el botón con icono de lápiz. El sistema lo redirigirá a un formulario con los datos precargados para su modificación.

![](/images/tipoProductos4.png)

---

**Paso 4: Eliminar tipo de producto**

Para eliminar un tipo de producto, el usuario debe presionar el botón con icono de bote de basura en el registro correspondiente y confirmar la acción.

![](/images/tipoProductos5.png)

---

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de tipos de productos en el sistema sigue el siguiente orden:

1. Ingresar a la sección de Tipos de Productos.  
2. Crear un nuevo tipo de producto.  
3. Editar el tipo de producto si es necesario.  
4. Eliminar el tipo de producto.
