# Módulo de Clientes en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el uso del módulo de
Clientes dentro del sistema web de Moteros Oaxaca. Este módulo permite
al Administrador y Vendedor administrar los clientes en el sistema.

### 1.1 Rol Requerido

El módulo de Clientes es accesible para usuarios con el rol de
Administrador y Vendedor.

## 2. Uso del Módulo de Clientes

A continuación, se describe paso a paso cómo el Administrador o Vendedor
puede utilizar el módulo de Reabastecimiento: acceder al dashboard,
consultar los clientes, aplicar filtros, ajustar precios y exportar la
información.

### 2.1 Acceso al Módulo de Reabastecimiento

**Paso 1: Navegar al módulo**

El Administrador debe dirigirse al menú lateral (sidebar) del sistema y
hacer clic en la opción \"Clientes\". Al seleccionarla, el sistema
redirige automáticamente al dashboard del módulo, donde se muestra el
Reporte de Ventas.

![](/images/clientes1.png)

### 2.2 Dashboard: Vista de clientes

El dashboard del módulo de Clientes presenta a todos los clientes
creados. Cada cliente tiene sus botones de control como el de edición y
eliminación:

![](/images/clientes2.png)

### 2.3 Crear un Cliente

El usuario debe presionar sobre el botón "Nuevo". Para ser redirigido a
un formulario en donde se llenarán los campos requeridos.

![](/images/clientes3.png)
![](/images/clientes4.png)

**Paso 3: Confirmar el ajuste**

Cuando el usuario termine de llenar el formulario podrá presionar el
botón de "Guardar"

  -----------------------------------------------------------------------
  **Nota:** Un dato importante a aclarar es que solo el Administrador
  puede asignar el tipo de cliente que es y activar el crédito motero.

  -----------------------------------------------------------------------

### 2.4 Editar Cliente

El usuario deberá presionar el icono de lápiz si desea editar al cliente
creado. El usuario será redirigido a un formulario con los datos
precargados para poder editar de una manera más cómoda la información
del usuario.

![](/images/clientes5.png)

  -----------------------------------------------------------------------
  **Nota:** Solo el administrador del sistema puede cambiar el tipo de
  cliente y el crédito motero.
  
  -----------------------------------------------------------------------

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de uso del módulo de Clientes
sigue el siguiente orden:

- Acceder al módulo desde la opción \"Clientes\" en el sidebar.

- Crear un nuevo cliente llenando el formulario solicitado.

- Para ajustar datos del cliente, hacer clic sobre icono de lápiz.

- Para eliminar a un cliente, hacer clic sobre el icono de basurero.
