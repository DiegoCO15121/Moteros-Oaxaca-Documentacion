# Módulo de Reportes: General

## 1. Introducción

El presente documento describe el proceso que debe seguir un usuario con el rol de administrador para acceder y utilizar la sección **General** del módulo de reportes del sistema web de Moteros Oaxaca. El objetivo es facilitar el análisis de información financiera y de ventas.

---

## 2. Flujo de Reporte General

### 2.1 Navegar a Reportes → General

El usuario debe dirigirse al menú lateral y seleccionar **Reportes**, posteriormente elegir la opción **General**.

![](/images/General1.png)

---

### 2.2 Visualización del Dashboard

Una vez dentro, el sistema permite aplicar filtros por:

- Fechas  
- Sucursales  
- Empleados  

El dashboard muestra:

- Resumen de ingresos y ventas por tipo de pago.  
- Información monetaria general de la empresa.  

![](/images/General2.png)

También se presenta:

- Top de vendedores con más ventas.  
- Top 5 productos más vendidos.  

![](/images/General3.png)

Finalmente, el sistema muestra una gráfica de tendencia de ventas por día junto con un resumen general.

![](/images/General4.png)

---

## 3. Resumen del Proceso

1. Ingresar a Reportes → General.  
2. Aplicar filtros según necesidad.  
3. Analizar ingresos y ventas.  
4. Revisar vendedores y productos destacados.  
5. Consultar tendencias de ventas.
