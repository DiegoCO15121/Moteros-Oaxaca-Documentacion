# Módulo de Reportes: Resumen de Sucursales

## 1. Introducción

Este documento describe el proceso para acceder y analizar la sección de **Reporte de Resumen de Sucursales** dentro del módulo de reportes.

---

## 2. Flujo de Reporte por Sucursal

### 2.1 Navegar a Reportes → Resumen de Sucursales

El usuario debe ingresar al módulo de **Reportes** y seleccionar **Reporte de Resumen de Sucursales**.

![](/images/ReporteResumenSuc1.png)

---

### 2.2 Visualización del Dashboard

El sistema permite filtrar por:

- Fechas  
- Sucursales  

El dashboard muestra:

- Resumen general de ventas y utilidades.  

![](/images/ReporteResumenSuc2.png)

Además, presenta:

- Ventas, utilidades, descuentos y devoluciones por sucursal.  
- Porcentaje de utilidad generado por cada sucursal.  

![](/images/ReporteResumenSuc3.png)  
![](/images/ReporteResumenSuc4.png)

---

## 3. Resumen del Proceso

1. Ingresar a Reportes → Resumen de Sucursales.  
2. Aplicar filtros.  
3. Analizar ventas y utilidades.  
4. Comparar desempeño entre sucursales.
