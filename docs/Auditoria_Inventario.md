# Flujo de Auditoría de Inventario en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de administrador para familiarizarse con el módulo de Auditoría de Inventario dentro del sistema web de Moteros Oaxaca. El objetivo de esta guía es proporcionar instrucciones claras y precisas que faciliten la operación diaria del sistema.

# 2. Flujo de Auditoría de inventario

A continuación, se describe paso a paso el proceso que debe seguir el usuario administrador para poder comprender el uso de Auditoría de Inventario.

### Paso 1: Navegar a Auditoría de Inventario

El usuario debe ubicar el módulo de Auditoría de inventario dentro la navegación del sidebar o en la barra de búsqueda de la parte superior.

![](/images/auditoriaInventario1.png)

El usuario será redirigido una interfaz en donde se encuentra información general sobre cada sucursal y sus auditorias hechas.

![](/images/auditoriaInventario2.png)

### Paso 2: Visualización de las auditorías

En caso de que el usuario quiera revisar los detalles de alguna auditoría, el usuario debe presionar el botón “Ver auditorías” en la sucursal que desee. El sistema redirigirá al usuario a un panel en donde puede ver las auditorias hechas y detalle de estas.

![](/images/auditoriaInventario3.png)

## 2.1 Aplicar Discrepancias a Inventarios

Algunas de las auditorias tendrán la opción de aplicar discrepancias al inventario. Para poder realizar esta acción, el usuario debe presionar sobre el botón amarillo con icono de herramienta para que el sistema pueda redirigir al usuario a una nueva página en donde puede aplicar auditoría al inventario.

![](/images/auditoriaInventario4.png)

![](/images/auditoriaInventario5.png)

Entre las cosas que se puede hacer dentro de esta página son: cambiar el concepto de la auditoría y cambiar la cantidad de productos en los cuales aplica el concepto.

## 2.2 Visualizar Detalles de la Auditoría

Para visualizar detalles de la auditoría, el usuario debe presionar el botón con icono de ojo y el sistema mostrara la información relacionada con la auditoria.

![](/images/auditoriaInventario6.png)

## 2.3 Descargar CSV de las auditorias

El sistema da la opción al usuario de descargar los datos de las auditorias en formato CSV, ya sea descargar todas las auditorias o solo una con el botón de descarga ubicado dentro de la auditoría.

# 3. Resumen del Proceso

A modo de referencia rápida, el flujo de Auditoría de Inventario en el sistema sigue el siguiente orden:

1.  Ubicarse en la sección de Auditoría de Inventario.

2.  Seleccionar la sucursal de interés.

3.  Seleccionar la auditoría de interés.

4.  Modificar las discrepancias del inventario.

5.  Visualizar detalles de la auditoría.

6.  Descargar auditoría.
