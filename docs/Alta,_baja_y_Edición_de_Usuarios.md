

# Flujo de alta, actualización y baja de usuarios en el sistema


## 1. Introducción

El presente documento describe de manera detallada el proceso que se
debe seguir para hacer el alta, actualización y baja de usuarios dentro
del sistema web de Moteros Oaxaca. El objetivo de esta guía es
proporcionar instrucciones claras y precisas que faciliten la operación
del sistema y poder unir más personal al equipo.

## 2. Flujo de Alta, actualización y baja de Usuarios

A continuación, se describe paso a paso el proceso que debe seguir el
usuario administrador para hacer un alta, actualización y baja de
usuario en el sistema de manera exitosa.

**Paso 1: Iniciar Sesión como administrador**

Se requiere de una cuenta de administrador del sistema para poder
ingresar las credenciales de manera correcta dentro del inicio de sesión.

![](/images/altaBajaUs1.png)

Al presionar el botón "Iniciar Sesión", el usuario será redirigido al
dashboard de información general del sistema. El usuario administrador
deberá navegar a la sección "Usuarios" para poder visualizar los
usuarios registrados en el sistema actualmente.

![](/images/altaBajaUs2.png)

**Paso 2: Crear Usuario**

Dentro del dashboard de usuarios, el usuario administrador debe
presionar en el botón "Nuevo" y deberá rellenar los campos solicitados.

![](/images/altaBajaUs3.png)

A continuación, se presenta un ejemplo del formulario debidamente
rellenado junto con los roles ya cargados en el sistema:

![](/images/altaBajaUs5.png)

En caso de que el formulario se haya llenado correctamente, el sistema
mostrará un aviso de confirmación de creación de usuario.

**Paso 3: Edición de usuario**

En caso de querer editar algún usuario previamente registrado. El
usuario administrador debe ubicarse dentro del dashboard de usuarios y
escoger el usuario a editar presionando sobre el icono de lápiz.

![](/images/altaBajaUs2.png)

Al momento de editar el usuario administrador encontrará en el
formulario los datos correspondientes al usuario a editar para poder
cambiarlos a gusto.

![](/images/altaBajaUs4.png)

- En caso de que el usuario administrador quiera reenviar la contraseña
  al usuario seleccionado lo puede hacer presionando en el botón de
  "Reenviar contraseña".

- Si el usuario desea descartar las modificaciones hechas, debe
  presionar en el botón "Regresar".

- Cuando el usuario este listo para guardar cambios este solo deberá
  presionar en el botón "Guardar".

**Paso 4: Eliminar Usuario**

El usuario administrador debe estar ubicado en el dashboard y presiona
en el botón con icono de bote de basura correspondiente al usuario a
eliminar.

![](/images/altaBajaUs2.png)

El sistema mostrará los datos del usuario a eliminar y el usuario
administrador decidirá si se procede con la eliminación del usuario o
desea descartar los cambios regresando al dashboard.

![](/images/altaBajaUs8.png)

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de alta, actualización y baja de
usuarios en el sistema sigue el siguiente orden:

1.  Iniciar sesión como administrador.

2.  Ingresar al panel de usuarios para visualizar las opciones de
    agregar, editar y eliminar.

3.  Para crear el usuario se deben llenar los datos requeridos por el
    sistema.

4.  Para editar el usuario se debe presionar sobre el botón de edición y
    con ello el sistema permite la modificación de datos del usuario.

5.  Para eliminar un usuario se debe presionar sobre el botón de
    eliminar y el sistema preguntará al usuario administrador si quiere
    realizar la acción.
