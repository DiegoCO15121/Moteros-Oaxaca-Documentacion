
# Flujo de Descuentos por Días Especiales

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de administrador para administrar los descuentos por días especiales en el sistema.

## 2. Flujo de Descuentos por Días Especiales

A continuación, se describe paso a paso el proceso que debe seguir el usuario administrador para manejar de manera adecuada el módulo de Descuentos por días especiales.

**Paso 1: Navegar a Descuentos por Días Especiales**

Para que el usuario pueda acceder al módulo de Cajas, se debe ubicar en la sección de “Cajas” de la navegación lateral.

![](/images/descuentosEspeciales1.png)

Una vez que se encuentre en la sección ya mencionada, el sistema mostrará un calendario con días marcados en donde existen descuentos.

![](/images/descuentosEspeciales2.png)

**Paso 2: Crear evento**

El usuario debe presionar el botón “Agregar evento” y el sistema desplegara un formulario para proporcionar información sobre el evento. Cuando el usuario termine de guardar su información, debe presionar el botón “Guardar”.

![](/images/descuentosEspeciales3.png)

**Paso 3: Comprobar creación del evento**

Una vez guardado el evento el sistema notificara al usuario que el proceso se hizo de manera correcta y se debe marcar el evento en el calendario.

![](/images/descuentosEspeciales4.png)

**Paso 4: Editar evento**

En caso de que el usuario quiera editar la información del evento, el usuario debe presionar sobre el evento marcado en el calendario, de esta manera el sistema desplegara el formulario con los datos precargados para editar la información del evento.

![](/images/descuentosEspeciales5.png)

**Paso 5: Eliminar evento**

Cuando el usuario pasa el cursor sobre el evento, se mostrará un icono de bote de basura con el cual el usuario puede interactuar y al presionarlo el sistema pedirá confirmar la eliminación.

![](/images/descuentosEspeciales6.png)

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de descuentos por días especiales en el sistema sigue el siguiente orden:

1.  Ubicarse en la sección de tipo de descuentos por días especiales.

2.  Crear un nuevo evento.

3.  Editar el evento.

4.  Eliminar el evento.
