# Módulo de Reportes: Clientes

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de administrador para ver el reporte correspondiente a los clientes y sus compras dentro del sistema web de Moteros Oaxaca. El objetivo de esta guía es proporcionar instrucciones claras y precisas que faciliten la operación diaria del sistema.

## 2. Flujo de Clientes 

A continuación, se describe paso a paso el proceso que debe seguir el usuario administrador para consultar el detalle de los clientes.

**Paso 1: Clientes**

El usuario debe dirigirse a la sección de “Clientes” dentro del módulo de Reportes

![](/images/reportesClientes1.png)

Dentro de esta sección el usuario puede filtrar a los clientes por medio de los filtros de fechas o si son parte del público general. También el usuario tiene la opción de buscar al cliente de manera directa en la barra de búsqueda.

![](/images/reportesClientes2.png)

En la interfaz se mostrará al cliente que más ha comprado en el rango de fechas especificado, al cliente que menos ha comprado y un total de ventas hechas. En la tabla se podrán visualizar registros con información del cliente, su producto favorito basado en lo que más compra y la fecha de su última compra.
