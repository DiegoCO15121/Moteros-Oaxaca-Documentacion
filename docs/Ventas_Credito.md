# Flujo de Ventas a Crédito en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario con el rol de administrador o vendedor para poder
visualizar las ventas a crédito dentro de la aplicación web Moteros
Oaxaca. El objetivo de esta guía es proporcionar instrucciones claras y
precisas que faciliten la operación diaria del sistema.

### 1.1 Rol Requerido

El módulo de Ventas a Crédito es accesible para usuarios con el rol de
Administrador y Vendedor.

## 2. Flujo de Ventas a Crédito

A continuación, se describe paso a paso el proceso que debe seguir el
usuario para utilizar el módulo de ventas a crédito.

### 2.1 Navegar a Ventas a Crédito

Para que el usuario pueda empezar a ver las ventas a crédito, se debe
ubicar en la sección de "Ventas a Crédito".

![](/images/ventasCredito1.png)

Una vez que se encuentre en la sección ya mencionada, el sistema mostrará
una interfaz con una barra de búsqueda para poder buscar registros entre
las múltiples ventas a crédito.

![](/images/ventasCredito2.png)

### 2.2 Ver detalles de ventas a crédito

Para ver los detalles de cada venta, el usuario debe presionar el botón
con icono de ojo y el sistema redirigirá al usuario a la sección de
detalles de la venta en donde puede realizar diferentes acciones,
especificadas en el menú superior.

![](/images/ventasCredito3.png)

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de ventas a crédito en el sistema
sigue el siguiente orden:

- Ubicarse en la sección de Ventas a Crédito.

- Buscar registros.

- Ver detalles de la compra y cambiar aspectos de esta.
