# Módulo de Reportes: Productos sin Ventas

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de administrador para ver los reportes correspondientes a los productos sin ventas dentro del sistema web de Moteros Oaxaca. El objetivo de esta guía es proporcionar instrucciones claras y precisas que faciliten la operación diaria del sistema.

## 2. Flujo de Productos sin Ventas 

A continuación, se describe paso a paso el proceso que debe seguir el usuario administrador para consultar los productos sin ventas.

**Paso 1: Productos sin Ventas**

El usuario debe dirigirse a la sección de “Productos sin Ventas” dentro del módulo de Reportes

![](/images/productosSinVentas1.png)

Dentro de esta sección el usuario puede filtrar el inventario por medio de los filtros de sucursales, proveedores, semáforo y la barra de búsqueda.

![](/images/productosSinVentas2.png)

El usuario puede ver el desglose del inventario si presiona sobre la sucursal deseada, después el usuario puede presionar sobre cualquier ubicación de los productos y el sistema mostrara los productos que se encuentra en la ubicación deseada junto con los detalles de estos.

![](/images/productosSinVentas3.png)
