# Gestión de Motocicletas en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario con el rol de Administrador para gestionar las
motocicletas dentro del sistema web de Moteros Oaxaca. El módulo de
Motocicletas permite registrar los modelos de motos disponibles en la
tienda, así como mantener actualizada su información. Esta guía cubre
cómo visualizar, crear, editar y eliminar motocicletas desde el panel de
administración.

### 1.1 Rol Requerido

El módulo de Motocicletas es accesible únicamente para usuarios con el
rol de Administrador. A continuación, se describe el rol relevante:

  --------------------- -------------------------------------------------
  **Rol**               **Permisos y Funciones**

  **Administrador**     Tiene acceso completo al módulo de Motocicletas.
                        Puede visualizar el listado de motocicletas,
                        registrar nuevos modelos, editar los existentes y
                        eliminarlos desde el dashboard del sistema.
  --------------------- -------------------------------------------------

## 2. Gestión de Motocicletas

A continuación, se describe paso a paso cómo el Administrador puede
gestionar las motocicletas del sistema: visualizarlas, registrar nuevas,
editarlas y eliminarlas.

### 2.1 Acceso al Módulo de Motocicletas

**Paso 1: Navegar al módulo**

El Administrador debe dirigirse al menú lateral (sidebar) del sistema y
hacer clic en la opción \"Motocicletas\". Al seleccionarla, el sistema
redirige automáticamente al dashboard de motocicletas.

![](/images/motocicletas1.png)

### 2.2 Dashboard de Motocicletas

Una vez dentro del módulo, el Administrador puede ver el listado
completo de motocicletas registradas en el sistema. Cada registro
muestra el modelo, la descripción y el año correspondiente.

Desde este dashboard es posible realizar las siguientes acciones:

- Buscar motocicletas mediante la barra de búsqueda en la parte
  superior.

- Editar un registro existente presionando el ícono de lápiz.

- Eliminar un registro presionando el ícono de papelera.

- Registrar una nueva motocicleta mediante el botón \"Nuevo\".

![](/images/motocicletas2.png)

### 2.3 Registrar una Nueva Motocicleta

**Paso 1: Abrir el formulario de nueva motocicleta**

Desde el dashboard de Motocicletas, el Administrador debe hacer clic en
el botón \"Nuevo\" ubicado en la esquina superior derecha de la
pantalla. Esto abrirá un formulario vacío para el registro del nuevo
modelo.

**Paso 2: Completar el formulario**

El formulario presenta los siguientes campos:

![](/images/motocicletas3.png)

**Paso 3: Guardar el registro**

Una vez que se hayan completado los campos requeridos, el Administrador
debe hacer clic en el botón \"Guardar\" para registrar la nueva
motocicleta en el sistema. Si desea cancelar la operación, puede
presionar el botón \"Regresar\".

  -----------------------------------------------------------------------
  **Nota:** Los campos \"Modelo\", \"Año\" y \"Color\" son obligatorios.
  Si se intenta guardar sin completarlos, el sistema mostrará un mensaje
  de advertencia y no permitirá continuar.

  -----------------------------------------------------------------------

### 2.4 Editar una Motocicleta

**Paso 1: Seleccionar la motocicleta a editar**

En el dashboard de Motocicletas, el Administrador debe localizar el
modelo que desea modificar y hacer clic en el ícono de lápiz que aparece
en la columna de \"Acciones\" correspondiente a ese registro.

**Paso 2: Modificar los datos**

El sistema abrirá el mismo formulario utilizado para registrar una
motocicleta, pero con los datos actuales del modelo precargados. El
Administrador puede modificar cualquiera de los campos disponibles.

![](/images/motocicletas4.png)

**Paso 3: Guardar los cambios**

Una vez realizadas las modificaciones necesarias, el Administrador debe
hacer clic en el botón \"Guardar\" para aplicar los cambios. Si desea
cancelar la edición, puede presionar el botón \"Regresar\".

### 2.5 Eliminar una Motocicleta

**Paso 1: Seleccionar la motocicleta a eliminar**

En el dashboard de Motocicletas, el Administrador debe localizar el
modelo que desea eliminar y hacer clic en el ícono de papelera que
aparece en la columna de \"Acciones\" del registro correspondiente.

![](/images/motocicletas5.png)

**Paso 2: Confirmar la eliminación**

Al presionar el ícono de eliminar, el sistema mostrará un mensaje de
confirmación solicitando al Administrador que verifique si desea
proceder con la eliminación. El Administrador debe confirmar la acción
para que el registro sea eliminado definitivamente del sistema.

  -----------------------------------------------------------------------
  **Nota:** La eliminación de una motocicleta es una acción permanente e
  irreversible. Se recomienda verificar que el modelo no esté asociado a
  productos activos antes de proceder con su eliminación.

  -----------------------------------------------------------------------

### 3. Resumen del Proceso

A modo de referencia rápida, las acciones disponibles en el módulo de
Motocicletas siguen el siguiente flujo:

- Acceder al módulo desde la opción \"Motocicletas\" en el sidebar.

- Visualizar el listado de motocicletas en el dashboard y usar la
  búsqueda si es necesario.

- Registrar una nueva motocicleta con el botón \"Nuevo\", completar el
  formulario y guardar.

- Editar una motocicleta presionando el ícono de lápiz, modificar los
  datos y guardar.

- Eliminar una motocicleta presionando el ícono de papelera y
  confirmando la acción.
