# Flujo de Devolución en el sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario con el rol de vendedor (seller) para hacer la
devolución de un producto dentro del sistema web de Moteros Oaxaca. El
objetivo de esta guía es proporcionar instrucciones claras y precisas
que faciliten la operación del sistema.

## 2. Flujo de Devolución

A continuación, se describe paso a paso el proceso que debe seguir el
usuario vendedor para hacer una devolución de un producto en el sistema
de manera éxitosa.

**Paso 1: Selección de Productos a devolver**

Con la caja abierta, el usuario deberá dirigirse a la sección de Ventas
para ver los ventas que se han hecho y poder ver el detalla de cada una
y asi poder seleccionar el producto a devolver .

![](/images/devoluciones1.png)

El usuario debe presionar en el icono de ojo para poder ver el detalle
de la venta y ahí se mostrarán los productos que se vendieron.

  --------------------------------------------------------------------
  **Nota:** No todos los productos tienen el icono con la flecha azul.
  Si el producto esta dentro de garantía entonces el icono de
  devolución aparece, caso contrario el producto no es elegible para
  ser devuelto.
  --------------------------------------------------------------------

![](/images/devoluciones2.png)

**Paso 3: Devolución de producto**

Para acceder a la devolución del producto, el usuario debe presionar en
el icono de devolución (flecha azul).

![](/images/devoluciones3.png)
Aparecerá un modal con un formulario requiriendo información sobre la
devolución. Dentro de la acción encontramos las opciones:

- Re-ingreso.

- Merma.

Se selecciona la opción de Re-ingreso para efectuar la devolución.
Después se añade un concepto a la devolución y por último el usuario
vendedor debe introducir su código de autorización.

Por último, el usuario vendedor confirma la devolución.

**Paso 4: Revisar el estado de la venta y stock**

Después de confirmar la devolución, el estado de la venta será
actualizado y también el estado de stock del producto.

![](/images/devoluciones4.png)

### 2.1 Verificación de actualización de stock

El usuario vendedor deberá dirigirse a la sección de Productos y buscar
el producto que fue devuelto para comprobar su nuevo stock.

![](/images/devoluciones5.png)

# 3. Resumen del Proceso

A modo de referencia rápida, el flujo de devolución en el sistema sigue
el siguiente orden:

1.  Abrir la caja correspondiente desde la sección de Inicio.

2.  Ingresar los datos de apertura de caja (efectivo, código de
    vendedor, nota opcional).

3.  Seleccionar la venta hecha con el o los productos a devolver.

4.  Revisar si el producto a devolver cumple con la garantía de la
    tienda.

5.  Rellenar el concepto de la devolución.

6.  Hacer clic en \"Confirmar devolución\" para completar el proceso.

7.  Validar el estado de la compra y en el stock del producto que la
    devolución se efectuó correctamente.
