# Flujo de Kardex en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el módulo Kardex
relacionado a los productos dentro del sistema web de Moteros Oaxaca.
El objetivo de esta guía es proporcionar instrucciones claras y precisas
que faciliten la operación diaria del sistema.

### 1.1 Rol Requerido

El módulo de Kardex es accesible para usuarios con el rol de
Administrador.

## 2. Flujo del Kardex

A continuación, se describe paso a paso el proceso que debe seguir el
usuario administrador para utilizar el módulo de Kardex de manera
adecuada.

### 2.1 Navegar a Kardex

Dentro del sidebar el usuario administrador debe ubicar la sección de
"Kardex".

![](/images/kardex1.png)

Una vez que se encuentre en la sección ya mencionada, el sistema mostrará
diferentes filtros y una tabla con los registros de los productos.

![](/images/kardex2.png)

### 2.2 Filtrar los Registros

Para poder buscar el o los registros deseados, el usuario se puede apoyar
de los diferentes filtros que existen: rango de fechas, sucursales,
código de producto, tipo de movimiento y concepto. Una vez seleccionado
los filtros y sus respectivos valores, el usuario debe presionar el botón
"Aplicar filtros". En caso de querer limpiar los filtros, el usuario
tiene un botón "Limpiar" para así deshacerse de todos los filtros.

![](/images/kardex3.png)

  -----------------------------------------------------------------------
  **Nota:** Cuando se aplica el filtro de merma también se puede apreciar
  la pérdida monetaria que tiene el negocio.

  -----------------------------------------------------------------------

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de Kardex en el sistema sigue el
siguiente orden:

- Ubicarse en la sección de Kardex.

- Aplicar los filtros deseados.

- Limpiar filtros.
