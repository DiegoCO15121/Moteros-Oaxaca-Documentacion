# Módulo de Capital Humano: Sección de Reloj Checador

## 1\. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de vendedor para usar la sección de Reloj Checador.

### 1.1 Rol Requerido para la Gestión

El módulo de General es accesible únicamente para usuarios con el rol de Vendedor.

## 2\. Gestión de Reloj Checador

A continuación, se describe paso a paso como el vendedor puede usar el reloj checador del sistema y poder registrar su asistencia.

### 2.1 Acceso al Módulo de Reloj Checador

**Paso 1: Navegar al modulo**

El vendedor debe dirigirse al menú lateral (sidebar) del sistema y hacer clic en la opción "Reloj Checador", ubicada dentro de la sección de Capital Humano. Al seleccionarla, el sistema redirige automáticamente al dashboard del módulo.

![](/images/relojChecador1.png)

### 2.2 Reloj y registro de asistencia

Una vez dentro del módulo, el vendedor puede ver una interfaz con un reloj y un espacio para digitar su código de acceso de vendedor. El vendedor solo debe insertar su código de acceso para poder proceder cono el registro de su asistencia.

![](/images/relojChecador2.png)
