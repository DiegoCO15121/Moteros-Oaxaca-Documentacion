# Centro de Capital Humano: Gestión de Temporadas bloqueadas


## 1\. Introducción

El presente documento describe de manera detallada el proceso que debe seguir un usuario con el rol de Administrador para gestionar las temporadas bloqueadas de trabajo dentro del módulo de Centro de Capital Humano del sistema web de Moteros Oaxaca. Las Temporadas bloqueadas definen periodos en los que no se puede solicitar permisos por parte de empleados.

### 1.1 Rol Requerido

El módulo de Centro de Capital Humano y la subsección de Temporadas bloqueadas son accesibles únicamente para usuarios con el rol de Administrador. A continuación, se describe el rol relevante:


### 1.2 Acceso al Módulo de Centro de Capital Humano

El Centro de Capital Humano agrupa diversas subsecciones relacionadas con la gestión del personal de la empresa. Para acceder a cualquiera de ellas, el Administrador debe seguir los mismos pasos descritos a continuación.

**Paso 1: Navegar al módulo desde el sidebar**

El Administrador debe dirigirse al menú lateral (sidebar) del sistema y hacer clic en la opción "Centro de Capital Humano". Al seleccionarla, el sistema redirige automáticamente al dashboard principal del módulo.

![](/images/centroCapitalHum1.png)

**Paso 2: Seleccionar la subsección de Temporadas bloqueadas**

Dentro del dashboard del Centro de Capital Humano, el Administrador puede visualizar todas las subsecciones disponibles organizadas en tarjetas. Para acceder a la gestión de puestos, debe hacer clic en la tarjeta "Temporadas Bloquedas" o presionar el botón "Ir" correspondiente.

![](/images/centroCapitalHum2.png)

## 2\. Gestión de Temporadas Bloqueadas

A continuación, se describe paso a paso cómo el Administrador puede gestionar las temporadas bloqueadas.

## 2.1 Dashboard de Temporadas Bloqueadas

Una vez dentro de la subsección, el sistema presenta un calendario del año con los días del mes actual y la visualización de días bloqueados marcados en rojo.

![](/images/temporadasBloqueadas1.png)

## 2.2 Crear un día bloqueado

**Paso 1: Presionar sobre el día deseado**

El usuario debe presionar sobre el día deseado para que el sistema muestre un formulario para llenar información relacionada sobre el día bloqueado.

![](/images/temporadasBloqueadas2.png)

## 2.3 Editar un Día Bloqueado o Eliminarlo

**Paso 1: Seleccionar día a editar o eliminar**

En el calendario, el usuario debe seleccionar el día que desea editar o eliminar y el sistema mostrara una ventana con la descripción editable y el botón de eliminar o guardar según lo que desee hacer el usuario.

![](/images/temporadasBloqueadas3.png)

**Paso 3: Guardar los cambios**

En caso de modificar datos, el usuario debe presionar el botón de “Guardar”.
