# Gestión de Cotizaciones en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario del sistema web de Moteros Oaxaca para gestionar
cotizaciones. Una cotización permite generar un resumen de productos con
sus precios para presentarlo a un cliente, sin necesidad de registrar
una venta de forma inmediata. Esta guía cubre cómo visualizar, crear,
editar, descargar y consultar los detalles de las cotizaciones.

### 1.1 Roles del Sistema

El módulo de Cotizaciones es accesible para los siguientes roles de
usuario:

  --------------------- -------------------------------------------------
  **Rol**               **Permisos y Funciones**

  **Administrador**     Tiene acceso completo al módulo de Cotizaciones.
                        Puede visualizar todas las cotizaciones del
                        sistema, crear nuevas, editarlas, consultar sus
                        detalles y descargarlas.

  **Vendedor**          Puede crear, visualizar, editar y descargar
                        cotizaciones dentro del sistema. Es el rol
                        responsable de generar cotizaciones para los
                        clientes durante el proceso de venta.
  --------------------- -------------------------------------------------

## 2. Gestión de Cotizaciones

A continuación, se describe paso a paso cómo el usuario puede gestionar
las cotizaciones del sistema: acceder al módulo, crear una nueva
cotización, guardarla, descargarla y consultar sus detalles.

### 2.1 Acceso al Módulo de Cotizaciones

**Paso 1: Navegar al módulo**

El usuario debe dirigirse al menú lateral (sidebar) del sistema y hacer
clic en la opción \"Cotizaciones\". Al seleccionarla, el sistema
redirige automáticamente al dashboard de cotizaciones.

![](/images/cotizaciones1.png)

### 2.2 Dashboard de Cotizaciones

Una vez dentro del módulo, el usuario puede ver el listado completo de
cotizaciones registradas en el sistema. Cada registro muestra el
cliente, el folio de la cotización, la fecha en que fue generada, el
vendedor que la creó y el costo total.

Desde este dashboard es posible realizar las siguientes acciones:

- Buscar cotizaciones mediante la barra de búsqueda en la parte
  superior.

- Consultar los detalles de una cotización presionando el ícono de ojo.

- Editar una cotización existente presionando el ícono de lápiz.

- Descargar una cotización presionando el ícono de descarga.

- Crear una nueva cotización mediante el botón \"Nuevo\".

![](/images/cotizaciones2.png)

### 2.3 Crear una Nueva Cotización

**Paso 1: Iniciar la nueva cotización**

Desde el dashboard de Cotizaciones, el usuario debe hacer clic en el
botón \"Nuevo\" ubicado en la esquina superior derecha de la pantalla.
Esto redirige automáticamente a la sección de Productos, desde donde el
usuario podrá agregar los artículos que desea incluir en la cotización.

![](/images/cotizaciones3.png)

**Paso 2: Seleccionar los productos**

En la sección de Productos, el usuario puede explorar el catálogo
disponible y utilizar la barra de búsqueda para localizar artículos
específicos. Al pasar el cursor sobre un producto, aparecen las opciones
para agregarlo al carrito. El usuario debe hacer clic en el ícono de
carrito del producto deseado para añadirlo a la cotización.

  -----------------------------------------------------------------------
  **Nota:** Solo los productos con existencia disponible en la sucursal
  mostrarán el ícono de carrito al pasar el cursor sobre ellos. Si un
  producto no muestra este ícono, indica que no cuenta con inventario
  disponible.
  
  -----------------------------------------------------------------------

**Paso 3: Revisar el carrito y guardar la cotización**

Una vez agregados los productos deseados, el usuario debe acceder al
carrito de compra. Desde esta vista, el usuario puede ajustar las
cantidades de cada producto, aplicar descuentos, seleccionar el cliente
y, en caso de contar con uno, aplicar un código de cupón.

En la parte inferior del panel lateral derecho, el usuario encontrará
las siguientes opciones:

- Guardar cotización: Guarda la cotización en el sistema sin
  descargarla.

- Guardar y descargar cotización: Guarda la cotización en el sistema y
  genera automáticamente un archivo descargable para compartir con el
  cliente.

![](/images/cotizaciones4.png)

  -----------------------------------------------------------------------
  **Nota:** Si el usuario desea continuar con el proceso de venta en
  lugar de solo guardar la cotización, puede presionar el botón
  \"Continuar al checkout\" para avanzar al proceso de pago.

  -----------------------------------------------------------------------

### 2.4 Consultar los Detalles de una Cotización

**Paso 1: Regresar al módulo de cotizaciones**

Una vez guardada la cotización, el usuario puede regresar al dashboard
de Cotizaciones para verificar que el registro fue guardado
correctamente. La nueva cotización aparecerá en el listado con su folio,
fecha, vendedor y costo total correspondientes.

**Paso 2: Ver los detalles del carrito**

Para consultar el detalle de los productos incluidos en una cotización,
el usuario debe presionar en el ícono de ojo de la cotización deseada.
El sistema mostrará una ventana con el desglose del carrito, que incluye
el nombre de cada producto, la cantidad y el precio unitario y total.

![](/images/cotizaciones5.png)

### 2.5 Editar una Cotización

**Paso 1: Seleccionar la cotización a editar**

En el dashboard de Cotizaciones, el usuario debe localizar la cotización
que desea modificar y presionar en el ícono de lápiz de la cotización
correspondiente.

**Paso 2: Modificar los productos o datos**

El sistema redirige al usuario a la vista del carrito con los productos
de la cotización precargados. Desde ahí, el usuario puede agregar o
eliminar productos, ajustar cantidades, modificar descuentos y
actualizar los datos del cliente.

**Paso 3: Guardar los cambios**

Una vez realizadas las modificaciones, el usuario debe presionar
\"Guardar cotización\" o \"Guardar y descargar cotización\" para aplicar
los cambios en el sistema.

### 2.6 Descargar una Cotización

El usuario puede descargar cualquier cotización registrada en el sistema
directamente desde el dashboard de Cotizaciones, haciendo clic en el
ícono de descarga del registro correspondiente. El sistema generará y
descargará automáticamente el archivo de la cotización para compartirla
con el cliente.

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de gestión de cotizaciones en el
sistema sigue el siguiente orden:

- Acceder al módulo desde la opción \"Cotizaciones\" en el sidebar.

- Visualizar el listado de cotizaciones en el dashboard y usar la
  búsqueda si es necesario.

- Crear una nueva cotización presionando \"Nuevo\", seleccionar los
  productos desde el catálogo y agregarlos al carrito.

- Desde el carrito, revisar los productos, aplicar descuentos si es
  necesario y presionar \"Guardar cotización\" o \"Guardar y descargar
  cotización\".

- Regresar al dashboard de Cotizaciones para verificar el registro
  guardado.

- Consultar el detalle de los productos de una cotización presionando el
  ícono de ojo.

- Editar una cotización presionando el ícono de lápiz, realizar los
  cambios y guardar.

- Descargar una cotización en cualquier momento desde el ícono de
  descarga.
