# Flujo de Reportes de Inventario en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario con el rol de vendedor para ver los reportes
correspondientes al inventario de los productos dentro del sistema web
de Moteros Oaxaca. El objetivo de esta guía es proporcionar
instrucciones claras y precisas que faciliten la operación diaria del
sistema.

## 2. Flujo de Reportes de Inventario 

A continuación, se describe paso a paso el proceso que debe seguir el
usuario vendedor para consultar el inventario de productos de forma
exitosa en el sistema.

**Paso 1: Inventario y Ubicación**

El usuario debe dirigirse a la sección de inventario y ubicación.

![](/images/inventario1.png)

Dentro de esta sección el usuario podrá filtrar los productos con los
que cuenta la sucursal por medio de nombres y ubicación dentro de la
sucursal.

![](/images/inventario2.png)

El usuario también puede descargar el inventario en formato PDF o CSV
(Excel) en caso de necesitarlo.

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de Reportes de inventario en el
sistema sigue el siguiente orden:

1.  Dirigirse a la sección de Reportes y seleccionar "Inventario y
    Ubicación".

2.  Buscar los productos de la sucursal por medio de su nombre o
    ubicación en la sucursal.

3.  Descargar el inventario.
