
# Gestión de Cotizaciones en Línea en el Sistema


## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario del sistema web de Moteros Oaxaca para gestionar
cotizaciones. Una cotización permite generar un resumen de productos con
sus precios para presentarlo a un cliente, sin necesidad de registrar
una venta de forma inmediata. Esta guía cubre cómo visualizar, crear,
editar, descargar y consultar los detalles de las cotizaciones en línea.

### 1.1 Roles del Sistema

El módulo de Cotizaciones en línea es accesible para los siguientes
roles de usuario:

  -----------------------------------------------------------------------
  **Rol**               **Permisos y Funciones**
  --------------------- -------------------------------------------------
  Administrador     Tiene acceso completo al módulo de Cotizaciones.
                        Puede visualizar todas las cotizaciones en línea
                        del sistema, crear nuevas, editarlas, consultar
                        sus detalles y descargarlas.

  Vendedor (Seller) Puede crear, visualizar, editar y descargar
                        cotizaciones dentro del sistema. Es el rol
                        responsable de generar cotizaciones en línea para
                        los clientes durante el proceso de venta. Es
                        importante recalcar que solo con este rol se
                        pueden editar o eliminar las cotizaciones en
                        línea.
  -----------------------------------------------------------------------

## 2. Gestión de Cotizaciones en línea

A continuación, se describe paso a paso cómo el usuario puede gestionar
las cotizaciones en línea del sistema: acceder al módulo, crear una
nueva cotización, guardarla, descargarla y consultar sus detalles.

### 2.1 Acceso al Módulo de Cotizaciones en línea

**Paso 1: Navegar al módulo**

El usuario debe dirigirse al menú lateral (sidebar) del sistema y hacer
clic en la opción \"Cotizaciones en línea\". Al seleccionarla, el
sistema redirige automáticamente al dashboard de cotizaciones en línea.

![](/images/cotizacionesLinea1.png)

### 2.2 Dashboard de Cotizaciones en línea

Una vez dentro del módulo, el usuario puede ver el listado completo de
cotizaciones registradas en el sistema. Cada registro muestra el
cliente, la fecha en que fue generada, la sucursal que la creo y el
status.

Desde este dashboard es posible realizar las siguientes acciones:

- Buscar cotizaciones mediante la barra de búsqueda en la parte
  superior.

- Consultar los detalles de una cotización presionando el ícono de ojo.

- Editar una cotización existente presionando el ícono de lápiz.

- Descargar una cotización presionando el ícono de descarga.

- Eliminar una cotización mediante el botón de eliminar.

![](/images/cotizacionesLinea2.png)

### 2.3 Crear una Nueva Cotización en línea

**Paso 1: Iniciar la nueva cotización en línea**

Para poder generar una nueva cotización, el usuario debe estar en el
home de la página de moteros y buscar productos de interés para la
cotización.

![](/images/cotizacionesLinea3.png)

**Paso 2: Seleccionar los productos**

En cada producto de interés, el usuario tiene que presionar el botón
"Agregar", para que los productos se agreguen al carrito.

**Paso 3: Revisar el carrito y guardar la cotización**

Una vez agregados los productos deseados, el usuario debe acceder al
carrito de compra. Desde esta vista, el usuario puede ajustar las
cantidades de cada producto, continuar comprando o proceder con la
compra. Cuando se finaliza la compra, la cotización se guarda en el
sistema.

![](/images/cotizacionesLinea4.png)

![](/images/cotizacionesLinea5.png)

### 2.4 Consultar los Detalles de una Cotización

**Paso 1: Regresar al módulo de cotizaciones en línea**

Una vez guardada la cotización, el usuario puede regresar al dashboard
de Cotizaciones en línea para verificar que el registro fue guardado
correctamente. La nueva cotización aparecerá en el listado con su
información correspondiente

**Paso 2: Ver los detalles de la cotización**

Para consultar el detalle de los productos incluidos en una cotización
línea, el usuario debe presionar en el ícono de ojo de la cotización
deseada.

![](/images/cotizacionesLinea6.png)

### 2.5 Editar una Cotización

**Paso 1: Seleccionar la cotización a editar**

En el dashboard de Cotizaciones, el usuario debe estar en el rol de
vendedor y tener una caja abierta para poder editar la cotización. El
usuario debe localizar la cotización que desea modificar y presionar en
el ícono de lápiz de la cotización correspondiente.

**Paso 2: Modificar los productos o datos**

El sistema redirige al usuario a la vista del carrito con los productos
de la cotización precargados. Desde ahí, el usuario puede agregar o
eliminar productos, ajustar cantidades y actualizar los datos del
cliente.

![](/images/cotizacionesLinea7.png)

**Paso 3: Guardar los cambios**

Una vez realizadas las modificaciones, el usuario debe presionar
\"Guardar cotización\" o \"Guardar y descargar cotización\" para aplicar
los cambios en el sistema.

### 2.6 Descargar una Cotización en línea

El usuario puede descargar cualquier cotización en línea registrada en
el sistema directamente desde el dashboard de Cotizaciones en Línea,
haciendo clic en el ícono de descarga del registro correspondiente. El
sistema generará y descargará automáticamente el archivo de la
cotización para compartirla con el cliente.

### 2.7 Eliminar una Cotización en línea

El usuario puede eliminar cualquier cotización en línea registrada en el
sistema directamente desde el dashboard de Cotizaciones en Línea,
haciendo clic en el ícono de basurero del registro correspondiente. El
sistema mostrará un resumen de la cotización y pedirá confirmación para
eliminar la cotización

![](/images/cotizacionesLinea8.png)

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de gestión de cotizaciones en
línea en el sistema sigue el siguiente orden:

- Acceder al módulo desde la opción \"Cotizaciones en línea\" en el
  sidebar.

- Visualizar el listado de cotizaciones en el dashboard y usar la
  búsqueda si es necesario.

- Crear una nueva cotización comprando desde la página en línea.

- Desde el carrito, revisar los productos y presionar \"Continuar\" y
  después "Finalizar Compra".

- Regresar al dashboard de Cotizaciones en línea para verificar el
  registro guardado.

- Consultar el detalle de los productos de una cotización presionando el
  ícono de ojo.

- Editar una cotización presionando el ícono de lápiz, realizar los
  cambios y guardar.

- Descargar una cotización en cualquier momento desde el ícono de
  descarga.
