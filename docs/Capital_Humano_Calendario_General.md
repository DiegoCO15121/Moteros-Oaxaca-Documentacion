# Centro de Capital Humano: Calendario General

## 1\. Introducción

El presente documento describe de manera detallada el uso de la subsección de Calendario General dentro del módulo de Centro de Capital Humano del sistema web de Moteros Oaxaca.

### 1.1 Rol Requerido

El módulo de Centro de Capital Humano y la subsección de Calendario General son accesibles únicamente para usuarios con el rol de Administrador. A continuación, se describe el rol relevante:


### 1.2 Módulo de Centro de Capital Humano

El módulo de Centro de Capital Humano agrupa diversas subsecciones relacionadas con la gestión del personal. Entre ellas se encuentra la subsección de Calendario general que sirve para establecer actividades en todas las sucursales.

![](/images/centroCapitalHum1.png)

## 2\. Uso de la Subsección Calendario General

A continuación, se describe paso a paso cómo el Administrador puede acceder al Calendario General para comenzar a administrar el horario de los trabajadores.

### 2.1 Acceso al Módulo de Centro de Capital Humano

**Paso 1: Navegar al módulo**

El Administrador debe dirigirse al menú lateral del sistema y hacer clic en la sección "Centro de Capital Humano" para expandirla. A continuación, debe seleccionar la opción "Calendario General". El sistema redirigirá automáticamente a la interfaz para ver el calendario general.

![](/images/centroCapitalHum2.png)

### 2.2 Calendario

Una vez dentro de Calendario general, el sistema mostrará un calendario con el mes actual seleccionado y este calendario puede tener días marcados con puntos rojos para indicar que hay una actividad establecida para ese día.

![](/images/calendarioGeneral1.png)

El sistema mostrará todos los eventos del mes de lado derecho. Tambien puede mostrar todos los eventos o actividades de un día si el usuario presiona el día deseado sobre el calendario.

### 2.3 Nueva Actividad

Para agregar una nueva actividad al calendario, el usuario debe presionar sobre el botón “Nueva actividad” y de esta manera el sistema mostrara un calendario con los datos necesarios para crear esa nueva actividad.

![](/images/calendarioGeneral2.png)

### 2.4 Eliminar una actividad

Para eliminar una actividad el usuario debe presionar sobre el día en donde se encuentra la actividad a eliminar dentro del calendario y con ello el sistema mostrará las actividades que están establecidas ese día en el recuadro de lado derecho. El administrador debe presionar el icono de bote de basura para poder eliminar la actividad.

![](/images/calendarioGeneral3.png)
