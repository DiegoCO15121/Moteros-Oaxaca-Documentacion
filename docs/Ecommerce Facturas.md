# Flujo de Facturación en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario con el rol de vendedor (seller) o administrador
(admin) para registrar una facturación dentro del sistema web de Moteros
Oaxaca. El objetivo de esta guía es proporcionar instrucciones claras y
precisas que faciliten la operación diaria del sistema.

### 1.1 Roles del Sistema

El sistema cuenta con diferentes roles de usuario, cada uno con permisos
específicos, pero para el flujo de facturación ambos usuarios hacen
prácticamente lo mismo con la única diferencia de que el administrador
del sistema puede ver las facturas globales de todas las sucursales y el
vendedor únicamente puede ver las facturas de la sucursal en la que se
encuentra.

## 2. Flujo de Facturación

A continuación, se describe paso a paso el proceso que debe seguir el
usuario vendedor o administrador para registrar una venta de forma
exitosa en el sistema.

**Paso 1: Facturas globales**

Para que el usuario pueda empezar a facturar las ventas que se han
hecho, se debe ubicar en la sección de facturación global.

![](/images/facturas1.png)

Una vez el usuario esté dentro de "Facturación global" este podrá
seleccionar una fecha específica para poder facturar las ventas hechas
ese día. En caso de que el usuario sea administrador, el sistema pedirá
seleccionar una sucursal. En caso de que el usuario sea vendedor, el
sistema tendrá selecciona la sucursal en la que se encuentra de manera
automática.

![](/images/facturas2.png)

![](/images/facturas3.png)

![](/images/facturas4.png)

**Paso 2: Proceso de facturación**

Para procesar la facturación de una venta, el sistema indicara porque me
dio de pago se hicieron las ventas y el usuario solo tendrá que
presionar el botón "Procesar Facturación" para ingresar a un resumen de
la operación y poder confirmarla presionando sobre "Emitir CFDI Global".
El sistema le permite seleccionar al usuario las ventas que desea
facturar

![](/images/facturas5.png)

Una vez que se haya emitido el CFDI Global, el sistema se actualizara y
marcara las facturas pendientes como completadas.

![](/images/facturas6.png)

El usuario también tendrá la posibilidad de ver sus facturas y
descargarlas presionando el botón de "Ver todas las facturas".

![](/images/facturas7.png)

### 2.1 Facturas Timbradas

Dentro de la sección de facturas timbradas el usuario podrá ver de una
manera más detallada las facturas que se han hecho, filtrando la
búsqueda con diferentes opciones para facilitar la localización de
documentos.

![](/images/facturas8.png)

El usuario tiene la opción de poder consultar el estatus de la factura
con el SAT, presionando en el botón "Ver información" y después
presionando en el botón "Consultar Estatus SAT".

![](/images/facturas9.png)

Si el usuario quiere descargar el PDF o XML de la factura, deberá
presionar el botón "Ver".

![](/images/facturas10.png)

De igual forma el usuario tiene la opción de descargar un ZIP con ambos
formatos comprimidos presionando el botón de "Descargar ZIP" y también
puede cancelar su factura presionando el botón "Cancelar".

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de facturas en el sistema sigue el
siguiente orden:

1.  Ubicarse en la sección de facturas globales.

2.  Identificar las ventas que se quieren facturar según su método de
    pago.

3.  Seleccionar las ventas a facturar y facturarlas.

4.  Revisar que las ventas se hayan facturado correctamente visualizando
    el PDF o XML.

5.  En caso de que el usuario quiera ver más a detalle las facturas que
    ha hecho. Puede ir a la sección de facturas timbradas y filtrar las
    facturas que ha hecho con diferentes opciones que proporcional el
    sistema.

6.  El usuario puede ver el detalle de las facturas, cancelarlas o
    descargar los archivos relacionados a ella.
