# Flujo de Cuentas de Banco en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario con el rol de administrador para administrar las cuentas
de banco en el sistema web de Moteros Oaxaca. El objetivo de esta guía es
proporcionar instrucciones claras y precisas que faciliten la operación
diaria del sistema.

### 1.1 Rol Requerido

El módulo de Cuentas de Banco es accesible para usuarios con el rol de
Administrador.

## 2. Flujo de Cuentas de Banco

A continuación, se describe paso a paso el proceso que debe seguir el
usuario administrador para manejar de manera adecuada el módulo de Cuentas
de Banco.

### 2.1 Navegar a Cuentas de Banco

Para que el usuario pueda acceder al módulo de Cuentas de Banco, se debe
ubicar en la sección de "Cuentas de Banco" de la navegación lateral.

![](/images/cuentasBanco1.png)

Una vez que se encuentre en la sección ya mencionada, el sistema mostrará
las cuentas de banco registradas con opciones para agregar más, editar,
buscar y eliminar.

![](/images/cuentasBanco2.png)

### 2.2 Crear una nueva cuenta

Para crear una nueva cuenta de banco el usuario debe presionar "Nuevo" y
el sistema mostrará un formulario para proporcionar información acerca de
la nueva cuenta de banco.

![](/images/cuentasBanco3.png)

### 2.3 Editar cuenta de banco

Para editar una cuenta de banco el usuario debe presionar el botón con
icono de lápiz y será redirigido a un formulario con los datos precargados
para editar los datos de la cuenta.

![](/images/cuentasBanco4.png)

### 2.4 Eliminar cuenta de banco

Para poder eliminar una cuenta de banco es necesario que el usuario
presione el botón de bote de basura en el registro que quiere eliminar y
después confirmar la eliminación.

![](/images/cuentasBanco5.png)

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de cuentas de banco en el sistema
sigue el siguiente orden:

- Ubicarse en la sección de cuentas de banco.

- Crear nueva cuenta de banco.

- Editar la cuenta de banco.

- Eliminar cuenta de banco.
