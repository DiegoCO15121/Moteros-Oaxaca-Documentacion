# Módulo de Ventas en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el uso del módulo de Ventas dentro del sistema web de Moteros Oaxaca. Este módulo permite consultar el historial de ventas registradas en el sistema, visualizar el detalle de cada transacción y realizar acciones como imprimir el ticket, facturar la venta o compartir el comprobante por WhatsApp. Esta guía está dirigida a los usuarios con rol de Administrador y Vendedor.

## 2. Uso del Módulo de Ventas

A continuación se describe paso a paso cómo el usuario puede consultar el historial de ventas y realizar las acciones disponibles sobre cada registro.

### 2.1 Acceso al Módulo de Ventas

**Paso 1: Navegar al módulo**

El usuario debe dirigirse al menú lateral (sidebar) del sistema y hacer clic en la opción "Ventas". Al seleccionarla, el sistema redirige automáticamente al dashboard del módulo, donde se muestran los registros de todas las ventas realizadas.

![](/images/mVentas1.png)

### 2.2 Dashboard del Historial de Ventas

Una vez dentro del módulo, el usuario puede visualizar el listado completo de ventas registradas en el sistema. Cada registro muestra información relevante de la transacción, como el cliente, la fecha, el monto y el vendedor asociado.

Para cada venta registrada, el usuario dispone de las siguientes acciones en la columna de "Acciones":

- Imprimir (ícono de impresora): Genera e imprime el ticket o comprobante de la venta.

- Ver detalles (ícono de ojo): Muestra el detalle completo de la venta seleccionada.

- Facturar (ícono de factura): Permite iniciar el proceso de facturación de la venta.

- Enviar por WhatsApp (ícono de WhatsApp): Comparte el ticket o comprobante de la venta directamente al cliente por WhatsApp.

![](/images/mVentas2.png)

> Nota: La disponibilidad de las acciones (facturar, enviar por WhatsApp) puede variar según la configuración de la sucursal y el estado de la venta.

### 2.3 Ver los Detalles de una Venta

**Paso 1: Seleccionar la venta a consultar**

En el dashboard de Ventas, el usuario debe localizar la venta que desea consultar y hacer clic en el ícono de ojo que aparece en la columna de "Acciones" del registro correspondiente.

**Paso 2: Revisar el detalle de la venta**

El sistema mostrará una vista con el detalle completo de la venta seleccionada. Esta vista incluye la información del cliente, los productos vendidos con sus cantidades y precios unitarios, los descuentos aplicados, el método de pago utilizado, el vendedor que registró la venta y el total de la transacción.

![](/images/mVentas3.png)

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de uso del módulo de Ventas sigue el siguiente orden:

- Acceder al módulo desde la opción "Ventas" en el sidebar.

- Visualizar el historial de ventas en el dashboard.

- Para imprimir el comprobante de una venta, presionar el ícono de impresora del registro correspondiente.

- Para consultar el detalle de una venta, presionar el ícono de ojo del registro correspondiente.

- Para facturar una venta, presionar el ícono de factura del registro correspondiente.

- Para enviar el comprobante por WhatsApp, presionar el ícono de WhatsApp del registro correspondiente.
