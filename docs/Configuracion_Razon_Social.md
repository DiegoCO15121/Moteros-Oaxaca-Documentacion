# Flujo de Configuración de Razón Social en el Sistema

## 1. Introducción

El presente documento describe de manera detallada el proceso que debe
seguir un usuario con el rol de administrador para administrar la razón
social de la empresa en el sistema web de Moteros Oaxaca. El objetivo de
esta guía es proporcionar instrucciones claras y precisas que faciliten
la operación diaria del sistema.

### 1.1 Rol Requerido

El módulo de Configuración de Razón Social es accesible para usuarios con
el rol de Administrador.

## 2. Flujo de Configuración de Razón Social

A continuación, se describe paso a paso el proceso que debe seguir el
usuario administrador para manejar de manera adecuada el módulo de
Configuración de Razón Social.

### 2.1 Navegar a Configuración de Razón Social

Para que el usuario pueda acceder al módulo de Configuración de Razón
Social, se debe ubicar en la sección de "Configuración de Razón Social" de
la navegación lateral.

![](/images/razonSocial1.png)

Una vez que se encuentre en la sección ya mencionada, el sistema mostrará
una interfaz para poder editar los datos que se usan para la facturación
de la empresa.

![](/images/razonSocial2.png)

### 2.2 Editar datos relacionados a la empresa

El formulario que se encuentra ubicado a la derecha sirve para editar
datos de la empresa que se usan para la generación de facturas.

### 2.3 Editar color primario de la factura

El sistema también permite cambiar el color primario de la factura el cual
se puede apreciar principalmente en la cabecera de la factura.

### 2.4 Editar Logo

El usuario puede cambiar el logo que aparecerá en la factura cargando uno
nuevo o en su defecto eliminar el que ya se tiene.

### 2.5 Editar CSD

El sistema permite configurar y cargar información como la clave privada,
certificado público, contraseña.

## 3. Resumen del Proceso

A modo de referencia rápida, el flujo de configuración de razón social en
el sistema sigue el siguiente orden:

- Ubicarse en la sección de configuración de razón social.

- Editar datos a preferencia del usuario.
